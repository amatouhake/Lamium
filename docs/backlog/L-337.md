# L-337 Minimap: one size setting instead of two

Kind: Ready (settings format change, agreed)
Status: Open, not started; direction agreed 2026-11-15

The minimap's side is "Map size" (10-50 % of the screen height) times the
element's HUD scale, so two settings change its size, unlike every other
element (maintainer 2026-11-14).

## Decided
Maintainer 2026-11-15:
- Only the HUD scale stays: "Map size" goes. The layout editor's scale
  handles are how every element is sized, and they move the scale.
- At 100 % the side is 20 % of the screen height (today's default), so a
  default install looks the same.
- Saved values convert once: new scale = old scale x (map size / 20),
  rounded to the 5 % step and clamped to 50-200 %. `map.size` is read only
  for that and no longer written.
- Accepted: the largest side becomes 40 % of the screen height; text grows
  with the map like any element (HUD text is the setting for smaller text).
  No minimap-only scale limit.

## Next
Pure conversion with a test, the map's side from the scale, remove the row
and its strings. In game: an existing settings file keeps the same size.
