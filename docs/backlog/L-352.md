# L-352 More on and off forms as a wrong state

Kind: Ready (small)
Status: Built 2026-11-17, not checked in game

"Lit and inverted forms as a wrong state" (`litAsState`, L-262) turns a
block id pair that Java Edition keeps as one block with a state into a
wrong state with a "Lit"/"Powered"/"Inverted" row instead of a wrong block.

## Decided
- Pairs (`nameRules` in `CheckRules.h`, Bedrock 1.26.60 ids): redstone
  lamp, repeater, comparator, redstone torch (L-262); `furnace`,
  `blast_furnace`, `smoker`, `redstone_ore`, `deepslate_redstone_ore` and
  their `lit_` forms (Java `lit`); `daylight_detector` /
  `daylight_detector_inverted` (Java `inverted`, an "Inverted" row; daylight
  changes only `redstone_signal`, under "Ignore redstone signal").
- Not: `lit_pumpkin` (the jack o'lantern is its own block in Java too).
- Name (maintainer 2026-11-17): "Lit and inverted forms as a wrong state" /
  「点灯・反転で分かれたブロックを状態違いにする」 / 「将点亮/反转形态视为状态错误」
  / 「將點亮/反轉形態視為狀態錯誤」; the help lists the blocks. The settings
  key `litAsState` and the action id stay.
- With L-183's placement-wide rules a pair's row is an item that can be
  ignored for one placement (for example the furnaces' Lit).

## Next

an inverted daylight detector, with the switch on and off.
