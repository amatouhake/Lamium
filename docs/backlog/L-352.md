# L-352 More on and off forms as a wrong state

Kind: Design (small)
Status: Proposed by the maintainer 2026-11-15; the wording waits for an answer

"On and off redstone blocks as a wrong state" (`litAsState`, L-262) turns
a block id pair that Java Edition keeps as one block with a state into a
wrong state with a "Lit"/"Powered" row instead of a wrong block. Today it
covers the redstone lamp, repeater, comparator and redstone torch
(`CheckRules.h`). Bedrock has more such pairs.

## Candidates (Bedrock 1.26.60 ids)
- `furnace` / `lit_furnace`, `blast_furnace` / `lit_blast_furnace`,
  `smoker` / `lit_smoker`: Java `lit`; lit by the game while smelting.
- `redstone_ore` / `lit_redstone_ore` and the deepslate pair: Java `lit`;
  lit by the game when touched.
- `daylight_detector` / `daylight_detector_inverted`: Java `inverted`;
  included (maintainer 2026-11-15) as an "Inverted" row. The id changes on
  a player's use; daylight changes only its signal (`redstone_signal`,
  already under "Ignore redstone signal").
- Not: `lit_pumpkin` (the jack o'lantern is its own block in Java too).

## Proposed
- Add the five lit pairs and the daylight detector to the table (a row
  each, no code).
- Rename away from "redstone", covering "inverted" too, for example "Lit
  and inverted forms as a wrong state" / 「点灯・反転で分かれたブロックを
  状態違いにする」, help listing the blocks; the settings key `litAsState`
  and the action id stay.
- With L-183's placement-wide rules a pair's "Lit" row becomes an item that
  can be ignored for one placement (for example the furnaces' Lit).

## Open
- Final wording in four languages (the name above is a proposal).
