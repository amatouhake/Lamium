# L-336 HUD layout: choose each element's contents in the editor

Kind: Ready (strong model)
Status: Open, not started; direction agreed 2026-11-15

Info HUD's lines are chosen in the HUD layout editor, while other elements'
contents (Durability HUD's offhand, armor, elytra, ammo; Target's rows;
Inventory HUD's hotbar) are only switches in the settings table. Make them
work the same way (maintainer 2026-11-14). The gain: an element's size
changes with its contents, so choosing them while placing it saves a trip to
the settings table.

## Decided
Maintainer 2026-11-15:
- Info HUD's "Lines" popover becomes one shared "Contents" popover in the
  shared widget files, fed per element by a list of switches and whether
  they can be reordered.
- Reordering stays Info HUD's alone; every other element gets switches
  only (their order is fixed by the layout).
- The rule for what goes in the editor: switches for what an element shows.
  Look choices (Durability's bar/number look, Target's hearts/bar/number)
  and behavior settings stay in the settings table only.
- The settings rows stay, as they do for Info HUD.
- Elements in the first step: Info HUD, Durability HUD (offhand, armor,
  elytra, ammo), Target (icon, ID, health, armor, growth, other details),
  Inventory HUD (hotbar), Used slots HUD (hotbar).

## Next
Build it; in game, open the editor, switch each element's contents and see
the element follow.
