# L-357 HUD elements: their size and their text size apart

Kind: Design
Status: Direction set by the maintainer 2026-11-17 (standard-size text, on or off per element); details to agree

An element's one scale (HUD layout editor, 50-200 %) sizes everything in it:
graphics and text together. So an element cannot be large with small text.
The minimap is where it showed first: its size moved into the editor alone,
which made its text large, and a separate "Text size" (`map.textSize`) was
added that multiplies with the scale, so the text still changes with the
map's size. The maintainer: handle it for the HUD as a whole, the map being
the first case, not a special one (2026-11-17).

## Decided
- One answer for every Lamium HUD element and the HUD layout editor; the
  minimap's text size is folded into it, not kept as its own rule.

## Open
- Direction (maintainer 2026-11-17, replacing the demo's candidates and the
  list-of-sizes proposal): per element a two-way choice, text at the
  standard size (as at 100 %, ignoring the element's scale) or text
  following the scale as today. No per-element text sizes; if a text size
  is ever wanted, one Lamium-wide setting (the game's GUI scale already
  sizes everything). To agree:
  - Where the choice sits without lengthening the toolbar (some toolbars
    are already full): with background and shadow in one "Look" popover,
    or in the Contents popover.
  - Defaults: saved layouts keep following the scale (nothing changes);
    whether new installs start at the standard size for elements with
    graphics (minimap, inventory grid, durability, status effects, ...).
  - `map.textSize` goes (a settings format change); a minimap with a value
    other than 100 % then shows text at the standard size or following.
  - Text on graphics (a slot's count) may have to keep following, or it
    would not fit its cell at small scales.
- The game's own HUD parts (position and scale only today).

## Next
Agree the points above, then make it Ready. The first demo
([demos/hud-text-size.html](../demos/hud-text-size.html)) shows the older
candidates only.
