# L-403 Diagnostic build options: remove with their item, or keep them compiling

Kind: Refactor
Status: Open; the policy is not chosen

`xmake.lua` has 43 diagnostic options (trace, probe, perf). Their code is
about 7,400 lines (3,000 in `src/features/research`, the rest in 40 files
named Trace or Probe beside the features), and `#if LAMIUM_...` blocks sit
in 62 files. None is built in CI (GAME-UPDATES.md says so), so an SDK move
breaks them unseen.

## Open
- A: a trace leaves with its item. When an L-item closes, its option, files
  and guards are deleted in the same commit; git keeps them.
- B: keep them, and CI compiles them: one job that builds with every option
  on (compile only), or a weekly one.
- Which of today's options to delete now under A.

## Known
- 2026-11-24, by the item numbers in each option's description: 19 name
  only finished items (`research_trace`, `slime_trace`, `playerlist_trace`,
  `portal_trace`, `edge_trace`, `trade_trace`, `slot_trace`,
  `creative_trace`, `hunger_trace`, `consumption_trace`, `offhand_trace`,
  `pick_trace`, `sneak_trace`, `book_paste_trace`, `effects_trace`,
  `radar_icon_probe`, `edge_guard_perf`, `schematic_quad_trace`,
  `doll_trace`); 12 name an open item; 11 name none.
- `unverified_game` and `feature_skip` are standing tools, not traces.
- A trace option stays on in `xmake f` until given `=n`.
