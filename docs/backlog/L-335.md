# L-335 Rows under a switched-off feature are dimmed only in the middle

Kind: Ready
Status: Built on `74983a71`, not checked in game

With a feature switched off (seen with Durability HUD on `5359af0c`,
maintainer 2026-11-14), the dark band over its child rows starts right of
the tree guide and ends before the value column, so the left edge and the
values ("Bar and num...", "Edit in HUD layout >") stay at full strength.

## Decided
- The dimming covers the whole row, guide and value column included, in
  every feature (DESIGN "Settings screen": rows of a switched-off feature
  are drawn dimmed).
- The HUD layout link ("Edit in HUD layout >") is a command row and stays
  at full strength (maintainer 2026-11-14); only setting rows dim.
