# L-283 Stronger block outline and a crosshair face highlight

Kind: Design
Status: Open, not started; no release target selected

A more visible block outline (color, thickness, a see-through mode showing
all the cuboid's edges instead of only the visible ones) and a highlight of
the face the crosshair points at, for operations that rely on precise
angles. Requested on the Discord server 2026-10-29: the vanilla outline is
"way too inconspicuous".

## Decided
- Maintainer 2026-10-30: tools outrank visual enhancement. The face
  highlight and the outline's legibility are information and are the point
  of the item; free color/thickness choice is aesthetics and weighs less.
  Decide customization against the existing discipline (palette colors, the
  four shape colors), not a free picker.
- Settings: one feature switch with only the child options the design
  actually decides.

## Open
- Rendering path for the targeted block and its version sensitivity
  (capability gate, GAME-UPDATES entry).
- Depth order against the vanilla outline under the DESIGN world-overlay
  rule (position markers win, guides yield).
- Replace the vanilla outline or draw alongside it.
- Non-cuboid blocks (slabs, stairs, fences) whose selection shape is not the
  full cube.
- What see-through edges may draw over.
