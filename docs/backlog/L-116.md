# L-116 Raw materials from the game's recipes

Kind: Research, then Design
Status: Pure calculation built and tested, not wired to the Materials tab; what the client holds is unchecked in game

Show the raw materials needed for a schematic's missing blocks (logs for
planks, cobblestone for stone bricks) in the Materials tab, computed from
the recipes the client holds (`Level::getRecipes()`: crafting, furnace,
stonecutter). Chosen 2026-10-08 (L-93 screen review).

## Decided
- Recipes come from the game, not an outside calculator (ResourceCalculator's
  data is GPL-3.0; see SCHEMATIC.md).
- The calculation is pure logic with tests:
  `src/features/schematic/RawMaterials.h` takes the wanted items and one
  chosen recipe per craftable item and returns raw materials, crafts per
  intermediate with spare output, and items left raw because their recipes
  lead back to themselves (iron block and ingot). Needs are summed across
  the list before rounding to whole crafts. `tests/RawMaterialsTests.cpp`.

## Known
SDK 26.60.4 headers: `Recipes` holds `mRecipes` as tag -> id -> `Recipe`,
and `mFurnaceResults`; `Recipe` has `getResultItems()`,
`getIngredient(x, y)`, `getCraftingSize()`, `isShapeless()` (virtual),
`mMyIngredients`, `mTag`, `mPriority`. The client-side table can be walked
by name.

## Open
Choices for the maintainer, with the agent's recommendation (not decided):
- Several recipes for one item: prefer the crafting-table recipe with the
  highest `mPriority`, then stonecutter, then furnace; never a recipe whose
  ingredient is the item's own product (block from ingots, ingots from
  block).
- Ingredient with several choices (any planks): show one named group
  ("Any planks") rather than pick a wood type.
- Furnace steps: list the smelted input as raw; do not count fuel.
- Spare output (2 stone bricks left from a batch of 4): show only raw totals
  at first; the per-step list later.

## Next
Check in game what the client holds on a server, and how tag ingredients
("any log") and multi-step chains (cobblestone, stone, stone bricks) appear
in `RecipeIngredient`. Then decide the choices above and wire the tab.
