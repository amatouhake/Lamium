# L-282 Toggle Vibrant Visuals with a key

Kind: Research, then Design
Status: Open, not started; low priority, no release target

A key that switches Vibrant Visuals off (and on again) without opening the
vanilla settings screen, which is heavy on weak PCs (Discord request
2026-10-28; maintainer note 2026-10-30). The value is mostly the quick exit.

## Decided
- A convenience proxy for a vanilla setting, not information Lamium adds:
  decide whether to build only once the research prices the switch.

## Open
- Can the client change the vanilla graphics mode outside the settings
  screen (an options path the client owns)?
- What a switch costs mid-world (resource or shader reload, hitch, screen
  flash), and whether the vanilla setting persists the change.
- How version-sensitive the path is (Vibrant Visuals is still changing; a
  new hook needs a GAME-UPDATES.md entry and the capability gate).

## Next
Research the questions above.
