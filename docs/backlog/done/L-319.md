# L-319 Item details: Work Penalty first, then the unshown rest

Kind: Feature
Status: Done, released in 0.7.0 and checked in game; the unchecked cases are in VALIDATION.md and the pre-release checks

An item's tooltip tells what the client knows and the game does not print:
the anvil work penalty with its prior-use count first, then a suspicious
stew's effect, property values, the ID, tags and NBT. Maintainer's note
2026-11-07. Current behavior and decisions: [ITEM-DETAILS.md](../../ITEM-DETAILS.md).

## Decided
- Direction (maintainer 2026-11-13): "as much about an item as can be
  shown"; no list of further details is decided.
- Maintainer 2026-11-17: "Enchantability: 15" stays as it is (the help text
  explains it). Not built, by decision: the anvil repair material (belongs
  with a later recipe feature, not here); the grindstone's experience
  return (random, so no true value to show); firework details (the game
  already shows flight, shape and colors).
- The work penalty has its own capability and both it and the item data
  reads name Item details in the paused notice (ITEM-DETAILS "Version
  gate"); the earlier gaps there are closed.

## Next
