# L-348 Hide the game's position and days played lines

Kind: Ready
Status: Done 2026-11-15 on `10325a18`, confirmed in game by the maintainer

A player asked to hide the game's coordinates and days played (2026-11-15).
Both are world options ("Show Coordinates", "Show Days Played") the host
sets, so on a server the player cannot turn them off. Info HUD can show the
same values wherever the player wants, so only hiding is added; moving the
game's lines is not.

## Decided
Maintainer 2026-11-15:
- Two switches under Game HUD placement: hide the game's position line and
  hide its days played line, both default off. The game's settings are not
  changed.
- Info HUD's "Hide the game's paper doll and position under it"
  (`hudHidePaperDoll`) goes as a setting: where the Info HUD covers those
  parts, they are always hidden. Debug View's `debugHideVanilla` follows
  the same rule (always hidden while Debug View is open). The saved keys are
  no longer read or written.
- The paper doll is not part of this: the game's own settings hide it.

## Known
The days played line goes through L-145's path: in 1.26.60's vanilla
`ui.brarchive` (hud_screen) it is a sibling of the position panel with the
same shape, an image `number_of_days_played` holding the label
`number_of_days_played_text`, so the existing `SpriteComponent` /
`TextComponent` render hooks in `DebugVanillaHud.cpp` skip it by name. No
new hook; like the position line it only skips a draw, so it is not gated by
`versionSensitiveAllowed()` (a renamed control only stops the hiding).

## Chosen while building
Unattended build 2026-11-15, least surprising where the decision was silent:
- The two switches follow Game HUD placement's main switch like its parts
  (off: the game's lines are its own again).
- Debug View and Info HUD coverage still hide only the position line and
  paper doll, not the days played line (as before).
- The removed keys are deleted from the file on the next save.
