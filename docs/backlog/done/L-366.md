# L-366 Recipe screens look like the game's window and tooltip

Kind: Design
Status: Done 2026-11-19: built and seen in game (VALIDATION-LOG, L-366 entries)

The recipe view, the wanted items' window and a listed item's tooltip
copy the game only half way (a flat grey with a thin dark edge; Lamium's
dark fill with the game's purple frame), which reads as neither the game
nor Lamium. The game's tooltip for a slot went under the item list's band.
The recipe screens and the anvil's panels come in differently (maintainer
2026-11-19, from screenshots).

## Decided
- Look like the game, done properly (maintainer 2026-11-19): Lamium's
  translucent look was tried and was hard to read here, and these screens
  cannot match Lamium's anyway. `windowPanel` gets the game window's edge
  and corners; a listed item's tooltip gets the game tooltip's fill and
  frame. Both are shared widgets, so the wanted items' window follows.
- The game's tooltip goes over the bands (RECIPES.md "Behavior"), by
  replaying the game's call after them; a slot under an open window has
  none, nor a container preview. The bundle's tooltip still goes under
  the bands (seen in game 2026-11-19, but the covered slot's preview).
- Coming in, to try first (maintainer 2026-11-19): every part stands where
  the window rests and fades, as the game's dark layer does, the anvil's
  panels too; one tested function (`ui/WindowFade.h`). A window never
  seen is guessed centred.

## Decided (measured)
- From the game's own chest window and tooltip (PNG, UI zoom 75%, 3
  pixels a unit, 2026-11-19), in `ui/VanillaFrame.h` with tests: the
  window's black edge with cut corners, two units of white and of
  #555555 shadow, #C6C6C6 inside; the tooltip opaque #1B0C1B with a
  #2C0863 line one unit in, its upper right and lower left corners rounder
  than the other two, text 5 units in on every side, 10 a line.
- A listed item's lines keep the game's colors: each line is drawn in the
  color code its text starts in (`palette::vanilla::textCode`; blue
  measured as #447FFF), white without one.

## Left out
- A listed food's tip has no hunger icons (the game's tooltip does):
  with [L-363](../L-363.md).
- The container preview's frame keeps its older, lighter purple, not the
  tooltip's measured line.
- The tip is placed on whole units, so the box and text move together.
