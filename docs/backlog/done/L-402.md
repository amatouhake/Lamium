# L-402 Check that every feature handles leaving the world, a dimension change and focus loss

Kind: Refactor
Status: Done 2026-11-26; the table, its check and the three findings settled, the Sneak placement reset seen in game on `e82ea651`

AGENTS.md rule 3 (restore vanilla when disabled, on world exit and
dimension change, and on focus loss for a feature that holds input or
changes game state) is kept by each feature on its own. The check makes
each feature write its answer down.

## Decided (maintainer 2026-11-26)
- Features keep independent lifecycles (L-111); no shared `reset(reason)`
  hook (L-73 review, H).
- [LIFECYCLE.md](../../LIFECYCLE.md) has one line per feature row of
  `Runtime.cpp`; `scripts/Check-Lifecycle.ps1` (CI) fails on a missing or
  stray line. It proves the answer is written, not that the code does it.
- No shared world generation counter: only the recipe service and the
  minimap count worlds; the others count cancelled operations.
- An automatic item move that holds no input and ends by itself (Sort,
  Death layout, Tool Protection, Auto Elytra) may finish while the window
  is unfocused, as it would focused; rule 3 says so.
- Auto Attack/Use stays switched on through focus loss: a lock the player
  switched on, like Permanent Sneak and Sprint (rule 3). It clicks only on
  the gameplay screen, so it pauses while a menu is open (AUTOMATION.md).
- Sneak placement resets its sent sneak state and held use on world exit
  and stop, so a new world starts from vanilla's sneak.
