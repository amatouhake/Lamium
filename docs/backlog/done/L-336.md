# L-336 HUD layout: choose each element's contents in the editor

Kind: Ready (strong model)
Status: Done 2026-11-15 on `10325a18`, confirmed in game by the maintainer (Durability HUD seen)

Info HUD's lines were chosen in the HUD layout editor, while other elements'
contents (Durability HUD's offhand, armor, elytra, ammo; Target's rows;
Inventory HUD's hotbar) were only switches in the settings table. Make them
work the same way (maintainer 2026-11-14). The gain: an element's size
changes with its contents, so choosing them while placing it saves a trip to
the settings table.

## Decided
Maintainer 2026-11-15:
- One shared "Contents" popover (toolbar button "Contents", 「内容」) in the
  shared files, fed per element by a list of switches and whether they can
  be reordered. It replaces Info HUD's "Lines" popover.
- Reordering stays Info HUD's alone; every other element gets switches
  only (their order is fixed by the layout).
- The rule for what goes in the editor: switches for what an element shows.
  Look choices (Durability's bar/number look, Target's hearts/bar/number)
  and behavior settings stay in the settings table only.
- Each switch writes the settings row's own field; the settings rows stay.
- Elements in the first step: Info HUD, Durability HUD (offhand, armor,
  elytra, ammo), Target (icon, ID, other details), Inventory HUD (hotbar),
  Used slots HUD (hotbar).

Chosen by the implementer (2026-11-15, maintainer asleep; change freely):
- Target's health, armor and growth settings are looks without an off
  state (hearts/bar/number, icons/bar/number, bar/number), so they have no
  switch. Target's "Show position", "Show distance" and "Show schematic
  information" are on/off but were not in the agreed list; left out.
- A switch-only row flips anywhere along it; the toolbar keeps its place
  when the element shrinks and re-anchors only when it grows over it.
- The editor's samples are unchanged: with bare hands the Durability sample
  is one pickaxe, so its offhand and armor switches show a change only with
  real items worn or held; "Other details" changes nothing on the grass
  sample card.
