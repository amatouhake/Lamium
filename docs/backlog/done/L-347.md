# L-347 One place for passing notices, and the last UI leftovers

Kind: Refactor (agreed 2026-11-15)
Status: Done 2026-11-15 on `cb90d3f5`, confirmed in game by the maintainer

The leftovers of [L-341](L-341.md) in [L-342](L-342.md): passing
notices shown five ways with no rule (toasts, the settings footer, the world
map's notice, the calculator's note, the anvil panel's status line), the
world map's side list without a scroll bar, and a few color literals.

## Known
Results of actions inside a Lamium screen still go to the HUD toast (the
version copied, the map cache cleared, saved data switched), so with the
Toast element hidden in HUD layout nothing shows them.

## Decided
- Notices (maintainer 2026-11-15): a toast is for what happens in the world
  (keys, the schematic menu). Inside a Lamium screen a result goes to that
  screen's status line (the settings footer, the tool views' footers, the
  anvil panel's status lines); a screen without one (world map, calculator)
  shows it in one shared notice box above its bottom edge. Success white,
  failure `warning`.
- The world map's side list gets the shared scroll bar (press, drag, wheel
  as the other lists).
- Last literals become tokens or existing ones: the waypoint distance text
  `dim`, the move target's gray `faint`; the calculator's syntax colors, the
  map ground and the switch and slider shades get tokens of their own.
