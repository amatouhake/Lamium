# L-236 Rebuild only the ghost sections whose visible layer changed

Kind: Design, low priority
Status: Done 2026-11-15 on `10325a18`, confirmed in game by the maintainer (fence gates and water across a section border)

Under the Up to cut, the ghost redraw after each step of the cut takes a
noticeable while on a large schematic (maintainer, desert village,
2026-10-22); Only is fine. Not urgent: day-to-day work likely uses Only.
The cause was a per-placement cache key: moving the cut discarded and
rebuilt every 8-block section and re-resolved the palette. Now only the
sections whose shown cells (with the mesh's halo) change are rebuilt.

## Decided
- Each section gets a layer state, and unchanged sections are reused when
  the cut moves. `src/features/schematic/SectionLayers.h` gives a section's
  state under a `PlacedSlab` as a comparable value: hidden, whole, or the
  shown range on the cut's axis. Whole and hidden compare equal across
  axes, so only sections holding the cut differ when it moves.
  Tests: `tests/SectionLayersTests.cpp`.

- The renderer keeps a placement's resolved palette and its built sections
  when only its layer view changes (`meshKey` in `PlacementStore`, the draw
  key without the view). Each section records the value
  (`sectionLayersOf`, `GhostMesh.h`) for its cells widened by `meshHalo`
  (2: the mesh reads one cell around - faces, enclosure, liquid corners and
  flow, a door's other half - plus one in case the game's tessellator reads
  further) and clipped to the placed box; a section whose value differs is
  dropped and built again, as every section was before.
- Touching placements still rebuild fully when a neighbour's view changes:
  their key holds the neighbour's whole draw key (border faces).
  Tests: `tests/SectionLayersTests.cpp` (off-grid origin, Only step, All to
  Up to), `tests/CheckIgnoresTests.cpp` (`meshKey`).

## In game
- Frame check on a large placement (the desert village) while stepping an
  Up to cut: only the sections at the cut should rebuild; no stale faces
  toward the hidden layers next to the cut, also across section edges.

A cheaper step if it is still slow: keep the old sections drawn until their
replacements are built.
