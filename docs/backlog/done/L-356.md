# L-356 Save shapes per server, like waypoints and placements

Kind: Ready
Status: Done 2026-11-17, checked in game (VALIDATION-LOG "Night work merged")

Shapes are saved only in a local world (`<world>/lamium/shapes.json`,
`overlay/LocalShapePath.h`). On a server or a friend's world they are not
saved at all and are gone after leaving. The maintainer wants them kept per
server the way waypoints and placements are.

## Decided
- Kept per server under the same key as the server's other data
  (L-343: `config/servers.json`, one key for all kinds), so "Use this data",
  Delete and merging on the Saved data page cover shapes too.
- Merging adds shapes; one equal in kind, position, size and dimension to a
  shape in use is counted once (as waypoints and placements, L-343).
- Local worlds keep their shapes inside the world folder.
- The file follows the other kinds: `config/shapes/<key>.json`, beside
  `waypoints/<key>.json` and `schematics/<key>.json` (maintainer 2026-11-17).
- The Saved data page's details and its "holds more" notice count shapes.
- A friend's world (keyed by level id) saves them too, as the other kinds.
- Provisional (agent, 2026-11-17, not asked): deleting a local world's data
  on the Saved data page now also deletes its `lamium/shapes.json`, as it
  deletes the other kinds there. Before, a local world's shapes were left.
