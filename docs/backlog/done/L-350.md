# L-350 Waypoint distance: 3D by default, horizontal as an option

Kind: Ready
Status: Done 2026-11-15 on `b8ca5f83`, confirmed in game by the maintainer

Waypoint distances in the list, the world markers and the distance limit
were horizontal (since `d519dd97`), while temporary waypoints are reached
by 3D distance, so a waypoint far above or below read as 0 blocks away
(maintainer 2026-11-15). A distance of 0 reads like any other ("0 blocks
away"); there is no "Here".

## Decided
Maintainer 2026-11-15:
- A Waypoints setting "Distance: 3D / Horizontal", default 3D. The list,
  the detail pane, the world markers, the map's distance text and the
  marker distance limit follow it.
- Temporary waypoints keep arriving by 3D distance, whatever the setting.

## Built
`Settings::Map::waypointMeasure` (`map.waypointMeasure`, after "Show in
the world") and `map::waypointDistance` in Waypoints.h, used by the
Waypoints list and detail pane, the world markers and their limit, and the
world map's panel. Arrival calls it with 3D always.

Choices made without asking: the row sits right after "Show in the world";
"Horizontal" is 水平 / 水平; the world map's placement and shape rows stay
horizontal (areas have no height); with FreeCamera the markers measure from
the camera eye's height, as they already did for x and z.
