# L-349 Settings and HUD follow-ups from the 2026-11-15 check

Kind: Ready
Status: Done 2026-11-15 on `25d3bb83`, confirmed in game by the maintainer

Small changes the maintainer agreed after checking the night run's build.

## Decided
Maintainer 2026-11-15:
- Game HUD placement: the chat part starts as Standard, so switching the
  feature on moves nothing; choosing Placed puts it at the lower-left
  default. A saved chat state stays as it is. Keeps "a parent switch off
  disables its children" and "on changes nothing until moved" for every
  part.
- Settings table: the state column has one width on every row; a choice
  control never runs into the key column, even on a row with no key (long
  labels may be shortened).
- Minimap "Hide while Debug View is open": renamed so it says what is
  hidden (Lamium's Debug View hides the minimap), and given help text, in
  all four languages.
- Durability HUD: a "Main hand" switch, default on (today's look), in the
  settings rows and the editor's Contents popover.

## Chosen while building
- Chat: every file saved since Game HUD placement existed has
  `chatPosition`, so it keeps its choice. Only fresh settings, Reset, and a
  file from before the group with Chat position off get Standard.
- State column: only steppers (choices and typed numbers) take the one
  width (96 units, ending before the key column). Sliders and links keep
  spanning the state and key columns of a keyless row; the decision named
  choice controls. Typing a slider's value shows the stepper box in that
  same column, so on a keyless row it now sits left of the value text that
  was clicked rather than under it.
- Main hand: no help text (like Offhand). With every row off the HUD layout
  editor still shows its sample pickaxe so the element can be placed.
