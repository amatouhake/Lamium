# L-400 The UI token check sees packed colors

Kind: Refactor
Status: Done 2026-11-26; every choice built, the world map's framed rows seen in game on `52babf18`

`scripts/Check-UiTokens.ps1` stops new `Rgb{...}` literals outside the
shared widget files, but a color written as a packed integer
(`packColor(242, 204, 61)`, `0xff5a64ffu`) or as the game's own color type
(`mce::Color{.25f, ...}`) passes. The check learns these forms; literals
that are a palette token under another spelling use the token.

## Decided
- The check counts the new forms per file in `UiTokenBaseline.txt`, like the
  ones it already counts: a file may not go over its count.
- A literal is replaced only where it is the same color with the same
  meaning as a token (a shape's color on the map is the shape's color). A
  test holds the replacement to the bytes drawn before.
- Map content keeps its own colors (radar dots, cave shading, the waypoint
  color choices, face outlines, the minimap's mark outline, a radar face's
  grey): they are data of the picture, not screen chrome. They stay counted,
  as do the map region's empty-column sentinel, the saturation bar's gold
  and the item renderers' own colors (`HeldItem.cpp`, `ItemIcon.cpp`,
  `PreviewRenderer.cpp`, the schematic marks in `GhostMarks.cpp`).
- The Check tab preview's tints stay a second set beside `palette::notPlaced`,
  `mismatch` and `wrongState` (a texture multiplied by the flat colors would
  wash them out): `palette::previewNotPlaced`, `previewMismatch`,
  `previewWrongState` and `previewDim`, the bytes drawn before.
- The minimap's unrecorded ground is `panel` at alpha 150 and the FreeCamera
  arrow is `accent`: screen colors, so they follow the palette.
- `LockedTrades.cpp`'s tip and the HUD's own `slotCount` draw the game's
  look (its tooltip, the hotbar's count with its shadow), not Lamium's: they
  keep their colors and stay counted, as the item renderers do.
- The world map's list rows are `ui::rowBackground` rows (a frame around
  the selected one), not the settings sidebar's accent bar.

## Known
- The check's third kind, `packed`, matches `packColor(<number>`, an opaque
  eight-digit hex other than all ones and the alpha mask, and
  `mce::Color{<number>` with or without a name between (the first name of a
  declaration counts; a second one on the same line does not).
- `ui::packed(Rgb, alpha)` in `Widgets.h` gives a palette color in the
  bytes `map::packColor` writes, rounded; `tests/MapTests.cpp` holds it to
  the bytes the map drew shapes in before.
- Replaced: the four shape colors of the map's shape layer
  (`MapLayers.cpp`) and the shape layer's symbol on the world map's bar.
