# L-358 Realms joined through a friend share one data set

Kind: Research (Bug: GitHub issue #81)
Status: Closed 2026-11-28: shipped in 0.8.0; a Realm cannot be checked by the maintainer and is left to user reports (GitHub issue #81 closed)

A Realm joined through a friend comes without an address, so its data went
by the level id alone (the `world_` key of L-343). Two Realms of one friend
reported the same level id, so the second wrote into the first's data and
the map mixed both (user report on Discord, 2026-11-17). Data already mixed
cannot be separated.

## Decided
- A join the game says is in a Realm (`IMinecraftGame::isInRealm()`) whose
  Realm id is known keys its data `realm_<id>`, before the address is looked
  at. The id is the one in `MinecraftGame`'s reconnect cookie: a Discord
  user (2026-11-18) found `Realms::RealmId` there unique per Realm and fixed
  across sessions.
- The cookie is read at the join through the virtual
  `INetworkGameConnector::getReconnectionCookie()` (neither it, the setter
  nor the alternatives' destructors are exported; the copy is taken as
  bytes and never destroyed, a few hundred bytes a join): the
  `Realms::RealmId` alternative's 8 bytes, or
  `Social::MultiplayerGameInfo::realmId`. The layout is not in the SDK, so
  it is behind the `RealmIdentity` capability; no id or an unverified game
  falls back to the `world_` key, as before (maintainer chose this,
  2026-11-19).
- Every remote join logs whether the game says it is in a Realm; only then
  is the cookie read and its kind and id logged: that line is how a
  released build checks it. Outside a Realm nothing is read, so a server
  or a friend's world keeps no copy of its connection (review 2026-11-19).
- A Realm's data starts empty. The old `world_` data stays and can be chosen
  or merged on the Saved data page, which now allows both for a Realm and a
  friend's world, not only for a server.
- The Saved data page shows such data as "Realm"; the kind is recorded in
  `servers.json` (`worlds[].realm`), not guessed from the key.
- Worlds behind one Realm (its slots) are told apart by L-365.

- A friend's own worlds need nothing more: two worlds of one friend
  reported different level ids and kept apart (2026-11-19).
