# L-340 Settings grouping

Kind: Ready (strong model)
Status: Done 2026-11-23, checked in game (VALIDATION-LOG)

General is a mixed bag, HUD-wide settings sit away from HUD, offhand
settings are in five places, and Inventory grew to 18 features with the
recipe screens. More groups are fine; the sidebar cannot hold them all.

## Decided (maintainer 2026-11-22)
- Two levels. The sidebar holds a few **categories**; inside one, green
  headings name its **groups**. All, search results and Hotkeys head
  their rows by group (not by category), in category order; Hotkeys has
  no category filter, so the groups are its only headings.
- A category with one group (Actions, General) is headed by its own name
  in every view, like the others (maintainer 2026-11-23, after seeing it
  without). Otherwise a group's name never repeats its category's.
- Group names are searched, as section names are today.
- The sidebar's on/total count and Tab work per category.
- Reset category stays per category, not per group (no finer resets,
  L-46). While it waits for its second press, the footer names the groups
  it resets.
- Moving features changes presentation only: saved settings, ids and
  bindings stay. New names get all four languages.
