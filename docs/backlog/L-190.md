# L-190 Select several rows at once in list screens

Kind: Design for the whole
Status: Waypoints trial on branch `l-190-waypoint-selection`, not merged; waits for Shapes, schematic placements and the map side panel

In list screens select several rows and act on them together (for example
show, hide, delete). Maintainer idea 2026-10-14.

## Decided
Maintainer 2026-11-06:
- Lamium does not say it supports multiple selection until the lists that
  need it have it: those a player adds to without limit (Shapes, schematic
  placements, the map's side panel). Merge and announce together.
- `ui/RowSelection.h` (on the branch) is the shared part; each list's bulk
  actions are decided with it.
- No file format change. Waypoints first: Ctrl + click toggles a row,
  Shift + click takes a range, no drag selection; show, hide and delete
  together, delete with a second press. The death point stays single.

## Open

- For the lists other than Waypoints: drag selection versus dragging to
  scroll or reorder, and confirmation for destructive bulk actions
  (Waypoints settled both: no drag selection, delete needs a second press).
