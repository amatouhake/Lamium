# L-190 Select several rows at once in list screens

Kind: Ready (strong model)
Status: Waypoints trial on branch `l-190-waypoint-selection`; the other lists agreed 2026-11-15, not built

In list screens select several rows and act on them together (for example
show, hide, delete). Maintainer idea 2026-10-14.

## Decided
Maintainer 2026-11-06:
- Lamium does not say it supports multiple selection until the lists that
  need it have it: those a player adds to without limit (Shapes, schematic
  placements, the map's side panel), and the Schematics Check list (for L-183,
  maintainer 2026-11-15). Merge and announce together.
- `ui/RowSelection.h` (on the branch) is the shared part; each list's bulk
  actions are decided with it.
- No file format change. Waypoints first: Ctrl + click toggles a row,
  Shift + click takes a range, no drag selection; show, hide and delete
  together, delete with a second press. The death point stays single.

Maintainer 2026-11-15, for every list:
- Ctrl + click toggles a row, Shift + click takes a range; no drag
  selection (dragging keeps scrolling or reordering).
- The detail pane shows the last clicked row; a bar of bulk actions shows
  while two or more rows are selected.
- Ctrl + A selects all; Esc first clears the selection, then closes.
- Delete and other irreversible bulk actions need a second press.
- Bulk actions: Shapes show, hide, delete; schematic placements show, hide,
  delete (no bulk move or turn); the map side panel show and hide only
  (delete in each list's own screen); the Check list ignore as a whole
  block, un-ignore and show in world, built after L-183's mockup settles
  how ignored rows look.
