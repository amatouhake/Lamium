# L-190 Select several rows at once in list screens

Kind: Ready (strong model)
Status: Built on branch `l-190-waypoint-selection`, not checked in game

In list screens select several rows and act on them together (for example
show, hide, delete). Maintainer idea 2026-10-14.

## Decided
Maintainer 2026-11-06 and 2026-11-15:
- Lamium does not say it supports multiple selection until the lists that
  need it have it: Shapes, schematic placements, the map's side panel and the
  Schematics Check list (for L-183). Merge and announce together, so
  FEATURES.md and the README stay silent until then. No file format change.
- Every list: Ctrl + click toggles a row, Shift + click takes a range; no
  drag selection (dragging keeps scrolling or reordering). The detail pane
  shows the last clicked row; a bar of bulk actions shows while two or more
  rows are selected. Ctrl + A selects all; Esc first clears the selection,
  then closes. Delete and other irreversible bulk actions need a second press.
- Bulk actions: Waypoints, Shapes and schematic placements show, hide,
  delete (no bulk move or turn); the map side panel show and hide only.
  The Check list (ignore as one block, un-ignore, show in world) comes after
  L-183's mockup settles how ignored rows look.

## Built
Shared: `ui/RowSelection.h` (selection, bulk actions per list, the bar's
arming and layout, the Ctrl + A / Esc keys; tests in
`tests/RowSelectionTests.cpp`), `drawBulkBar` in `ListViewWidgets.h`,
`ShapesLayout::reserveBulkBar`. Waypoints, Shapes, the Placed tab and the
map's side panel use them.

Chosen without asking (least surprising):
- The bar takes the list's last row (the side panel: a row under the list):
  "N selected", then Show, Hide and the destructive Delete ("Delete N?"
  armed). Show and Hide set every row, not a toggle.
- Esc order: an edit, a draft or type choice, map panels and menus first;
  then several rows return to the shown one; then the screen closes. With
  one row Esc closes as before. Closing a screen keeps the shown row.
- The detail pane's own Delete still deletes only the shown row; its armed
  state is separate from the bar's, and any other press disarms both.
- After a bulk delete nothing is selected.
- Placed tab: the shown row is the schematic's selected placement, so it
  follows Ctrl/Shift clicks; Ctrl + A keeps it (with none, the first row).
  Rows are kept by session id; a bulk delete keeps the selected placement by
  id (`removePlacements`). Switching tabs clears the rows.
- Side panel: Ctrl/Shift + click neither moves the map nor selects the
  placement; several rows drop out when the layer or dimension changes.
  Ctrl + A acts while the panel is open.
- Shapes: the draft row never takes part; starting a draft clears the rows,
  and Ctrl + A does nothing while a draft or type choice is open.
- Ctrl + click on the only selected row leaves none selected. On the Placed
  tab the pane's Delete returns several rows to one (its neighbour).
  Bulk show, hide and delete save once (`overlay::shapes` id lists).
