# L-190 Select several rows at once in list screens

Kind: Ready (strong model)
Status: Follow-ups built on branch `l-190-waypoint-selection`, not checked in game

In list screens select several rows and act on them together (for example
show, hide, delete). Maintainer idea 2026-10-14.

## Decided
Maintainer 2026-11-06 and 2026-11-15 (the second round after the check):
- Lamium does not say it supports multiple selection until the lists that
  need it have it: Shapes, schematic placements, the map's side panel and the
  Schematics Check list (for L-183). Merge and announce together, so
  FEATURES.md and the README stay silent until then. No file format change.
- Every list: Ctrl + click toggles a row, Shift + click takes a range; no
  drag selection; Ctrl + A selects all; a plain click selects just that row.
  All selected rows have the same highlight; no row is kept as primary.
- Two or more rows: the right detail pane becomes a selection pane; no bar.
  "5 selected", a summary line ("Shown N / Hidden M"), then the names in list
  order as plain lines with the extras their list row shows (mark, distance,
  placements' progress), as many as fit, the last reading "N more". Show,
  Hide and Delete sit where the single pane's buttons sit, Delete in its
  place ("Delete N?" on the first press). No bulk move or turn.
- Lists share one column shape: mark (kind and color; Shapes' type is the
  mark), name, distance, the list's own column (placements: progress only),
  shown. Positions are in the detail panes only.
- The map side panel matches the others: names as space allows, Delete (two
  presses); its list keeps its height. On the map, Ctrl + click on a mark adds
  it to or drops it from the selection (no range, no box).
- Esc with several rows clears the selection, the next Esc closes as before.
- The Check list (ignore as one block, un-ignore, show in world) comes after
  L-183's mockup settles how ignored rows look.
- Open: the armed Delete wording ("Delete N?" is unlike the others); main
  is unifying it, reconcile at merge.

## Built
Shared: `ui/RowSelection.h` (selection, Esc clearing, names-fit, button
layout, `compactSelectionPane` for the map, `toggleListed` for map clicks;
`tests/RowSelectionTests.cpp`), `ui/ListColumns.h` (the column shape;
`tests/ListColumnsTests.cpp`), `ShapesLayout::selectionPane()`, and in
`ListViewWidgets.h` `drawSelectionPane`, `drawListHeadings`,
`listDistanceText`, `drawFootprintGlyph`. `map::remove` deletes several
marks. Waypoints, Shapes, the Placed tab (docked too) and the map panel use them.

Chosen without asking (least surprising):
- On a narrow pane Show and Hide narrow so they stay clear of Delete, which
  keeps its place and width. The map panel puts its buttons on its last row.
- Marks: waypoints' diamond or cross, shapes' existing type glyphs, a
  footprint in the map's placement color for placements (moved from the map
  into the shared widgets); dimmed when hidden or elsewhere.
- Distance as the Waypoints list measures it (`screen::distanceTo`): to a
  shape's center or a plane's origin ("-" for a following shape), to a
  placement's footprint center (its origin until the file is read). Another
  dimension shows its name there, so Shapes lost the "Dimension N" suffix. A
  narrow list drops the distance first, then its own column.
- The summary counts the shown flag only; in the map panel hidden names are
  faint (as its rows), elsewhere names in another dimension are.
- Map Ctrl + click: Shift + click on a mark is a plain click; a mark the list
  does not show (another layer, another dimension's waypoint) starts the
  rows again from it alone and switches the list; the map stays, no
  placement is picked. After a bulk Delete nothing is selected.
- The footer says "N selected" while several rows are selected.
- Placed tab: several rows pick no placement; the schematic's selected one
  stays until one row is picked. Rows are kept by session id.
- Closing a screen with several rows selected clears them; one row is kept.
- Show and Hide set every row, not a toggle; each bulk action saves once per
  kind; any other press disarms Delete.
- Side panel: Ctrl/Shift + click moves no map and picks no placement; a
  layer or dimension change drops several rows. Shapes: the draft row never
  takes part; starting a draft clears the rows.
