# L-167 Change the language and resource packs from inside a world

Kind: Research, then Design (strong model) for the remaining pack work.
Status: Partly done: Game language and Skip server resource packs shipped in 0.2.1; global pack stack work not chosen.

Switch the game's display language, and look at or change the global
resource pack stack, without leaving the world or server first.

## Decided
- Language (shipped, `9651b4e`): General settings > Game language, drawn
  inside Lamium's settings frame, lists all 29 game languages and applies
  through the game's own path, never by writing option memory. In-world
  switching is experimental, rate-limited with a notice (one change per 5 s
  since L-310; 12 switches in 23 s once froze the game).
- Vanilla baseline (1.26.51.01): the in-world settings drop the Language tab
  (static `not $is_pregame` condition; the controller still holds the list);
  in-world Global Resources lists the active packs with no control to change
  them.
- Skip server resource packs (shipped, maintainer 2026-10-14): one switch for
  remote servers, taking effect on the next join, with a notice when packs
  were left out (Lamium toast). The download/acceptance handshake is never
  changed or skipped; only local application is. Per-server and per-pack
  choice are not wanted now. The look matches vanilla on a required-pack
  server: the player's global packs are dropped too and Global Resources
  shows a gray page.
- World and server packs are never edited. Fail open: if the game's own
  apply path cannot be found, show nothing.

## Open
- Later (maintainer 2026-10-14): show the player's own global packs while
  skipping a server's packs. Needs research on reapplying the Global stack
  during a server session.
- General global stack editing (agent's proposal, not decided): first a
  read-only view of the active stack in-world; a change is not hot reloaded,
  so queue it, leave through vanilla's exit, apply with
  `ResourcePackManager::setStack` (the Global Resources path), rejoin the same
  local world. Rejoining a server only if the game keeps its address without
  Lamium storing it.
