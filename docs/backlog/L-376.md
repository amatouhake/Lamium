# L-376 Recipe view tabs by kind of work

Kind: Design
Status: Built and checked in game 2026-11-20; the layout is questioned (Open)

The recipe view has a tab per station, so a recipe several stations do
shows once in each (a steak in four tabs). Agreed in [L-371](L-371.md)
"Groundwork": tabs are kinds of work, each recipe once, with its stations
as icons.

## Decided
- Kinds: crafting, cooking (furnace, blast furnace, smoker, both
  campfires: the game files one recipe under those stations' tags),
  stonecutting, smithing; later brewing ([L-361](L-361.md)) and the like.
  A kind's tab shows its usual station; its name under the pointer lists
  the stations.
- Each recipe shows once, with the icons of the stations that do it.
  This replaces "a recipe under each station that does it" (RECIPES.md,
  2026-11-19); the icons keep its point.
- A station's recipes (R, a left press) are how it is made; its uses (U,
  a right press) first what it does, only the recipes it can do
  ("cooking (blast furnace)"), then the recipes it goes into, none
  twice. A station's icon by a recipe opens its uses.
- The plan does not count fuel, so it needs no station choice.

## Open
- Tabs per process as other viewers keep them (smelting, blasting,
  smoking, campfire cooking, a recipe in each tab that does it), with the
  tab's stations listed once beside it, against today's one cooking tab
  with stations on each recipe (maintainer 2026-11-20).
- "Place" for cooking: the game's furnace recipe book places an input;
  Lamium's place is for the crafting grids only.

## Known
- A merged recipe keeps its first station (the furnace for cooking) in
  the notes' key, so `recipes.json` did not change; a choice made at
  another station (blast furnace) before is no longer found.
- Smelting alternatives (raw iron or the ores) group only where their
  stations are the same, as they are in the game.
