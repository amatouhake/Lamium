# L-249 Show the chunks within simulation distance

Kind: Design / Research
Status: Research partly done: the client reads the range (4 in a local world); two checks left before the presentation is agreed

Let the player see which chunks are simulated (where mobs, crops and
redstone tick) without implying more than the game guarantees. Chunk
Borders (`src/overlay/ChunkBorders.h`) draws only the borders around the
player. User request 2026-10-23. No release target selected.

## Known
- SDK 26.60.4 headers: `ILevel::getChunkTickRange()` is virtual, so callable
  on the client level without a new symbol. `getChunkTickRangeManager()`
  gives `ChunkTickRangeManager` (`mChunkTickRange`,
  `isChunkInTickRange(LevelChunk, minDistToPlayer)`, `MCNAPI` so it does not
  link). `LevelSettings::mServerChunkTickRange` and
  `LevelData::mServerTickRange` hold the same number as data.
- Probe 2026-11-12 (`world_probe` build, VALIDATION-LOG):
  `getChunkTickRange()` on the client level returns 4 in a local world.
- Hypothesis: the server sends the range with the level settings at join,
  so "unknown on servers" may not happen.

## Open
- Does the value follow the world's setting (not just the default)? What
  does a server give?
- The simulated area's shape (square, circle or the chunk-distance rule
  `isChunkInTickRange` uses) and whether it is centred on each player: check
  in game, or request the function.
- Where to show it. Agent recommendation, not decided: a Chunk Borders
  option tinting the border lines of simulated chunks (that overlay already
  draws per chunk, no new screen); minimap or world map layer later, once
  the shape is confirmed.
- When the range cannot be read. Recommendation: draw nothing and say so in
  the option's description rather than assume a value.

## Next
Log `getChunkTickRange()` at world join in a local world at simulation
distance 4 and 8, then on a server whose distance is known (stand-ins only
in tracked files: never real hosts, IPs, ports or level ids). Then agree the
presentation with the maintainer.
