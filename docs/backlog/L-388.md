# L-388 One craft run for making a plan's steps and Mass Craft

Kind: Refactor (strong model)
Status: Open; waits for L-385's server check

`RecipePlace.cpp` holds four runs that drive the crafting screen frame by
frame: laying a recipe in (`going`), making a plan's steps (`making`),
crafting onto the pointer (`onto`) and Mass Craft (`massCraft::run`).
They repeat the same moves (wait for the grid to empty and clear it,
take the output as a Shift click does, drop the run when its screen
goes, log the end) with separate counters and patience.
