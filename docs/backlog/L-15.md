# L-15 Breaking and placement restrictions

Kind: Design (reopened); placement then needs Research
Status: Breaking shipped in 0.1.8 and stays until replaced; the whole plan is reopened for redesign before placement is built

Level ground and dig tunnels without breaking past a chosen level or face;
lay floors, walls and roofs flat without placing outside them. Placing with
a chosen facing is not wanted for now. Implementation notes:
[RESTRICTIONS.md](../RESTRICTIONS.md).

## Decided
Current breaking (plan of 2026-09-28, built with L-73 step 13, checked in
game 2026-10-08; it replaced the old capture/reset keys):
- The anchor is the block where the button press starts (first block mined);
  the restriction holds while the button stays held and ends on release.
- Rejected blocks never end the physical hold: back on an allowed block,
  breaking continues. A rejected block is silent (no sound, no toast).
- Modes: Layer (first block's Y); Height band (from the feet up N blocks,
  default 2, a setting; anchored at the feet); Plane (the mined face's
  plane); Line; Column.
- Keeps the existing Breaking Restriction toggle and Cycle Breaking Mode
  bindings (no new default keys); the saved mode carried over unchanged.
- While held, the allowed region shows as faint faces like Shapes, skipping
  the targeted block so the vanilla outline stays visible; the Status
  element shows the mode.
- The Actions category keeps one "Block Restrictions" group. The old capture
  and reset actions stay in `enum Action` (ids are saved) but are not shown
  or dispatched.

Placement as planned (before the redesign): modes chosen separately from
breaking so leveling and laying a floor can run at once; Layer, Plane (a
wall through the first placed block, oriented by the first clicked face),
Line, Column; anchored on the first placed block.

## Open
- The redesign (maintainer 2026-10-08/10): too many modes to cycle through;
  the placement mode has no key and does nothing yet. The maintainer is not
  satisfied with breaking either.
- Maintainer input (2026-10-13): a fixed height chosen on the spot. From the
  looked-at block or the feet, "keep everything at or below this Y" or
  "break only above this Y", boundary plane previewed and moved with the
  wheel; it stays in world coordinates until cleared. Open: clearing it,
  dimension changes, combining with fixed ranges. Ordinary mining and the
  existing modes must keep working.
- Later: shape-linked modes (inside a shape, on its surface).

## Next
1. Redesign with the maintainer (Design).
2. Placement gate (Research): Lamium already has cancellable
   `GameMode::buildBlock` / `SurvivalMode::buildBlock` hooks in the
   detached-camera interaction guard. Find whether that boundary can reject
   a whole placement before mutation, and how to derive the real destination
   cell/state with vanilla placement semantics (prefer a vanilla
   placement-prediction API) rather than assuming clicked block + face.
   Trace ordinary blocks, replaceable vegetation, slabs/snow, doors/beds,
   signs, redstone, waterlogged/merge cases and edge placements, without
   touching container use or buckets. RESTRICTIONS.md lists trace
   candidates. Stop and report if no safe path exists.
3. Placement modes (Ready once step 2 finds a path), faces and Status line.
   A settings change says so in the migration notes before the store changes.
