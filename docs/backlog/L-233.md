# L-233 Make inventory transfer gestures rebindable

Kind: Design, future
Status: Open, not urgent; nothing is blocked today

Now that a wheel direction can be part of a binding, make the transfer
gestures configurable instead of fixed to Shift/Ctrl/Alt plus wheel, drag
or click (maintainer 2026-10-20).

## Known
`src/features/inventory/transfer/TransferGesture.h` derives 14 gestures
(one/stack/matching/all on the wheel; stack/one/keep-one/drop drags;
matching/all clicks; cursor matching) from hardcoded modifiers. The settings
only enable or disable each gesture.

## Open
- Which gestures to expose and which model. Wheel gestures fit the existing
  Press-plus-wheel chords; drags are press-move-release and clicks carry
  cursor state, so plain chords cannot express them without a gesture model.
- Modifier roles, defaults matching today, the container-only context,
  conflicts with other actions, whether to start with the wheel subset only.

## Next
Do not start without choosing the subset and model. L-169 owns transfer
extensions.
