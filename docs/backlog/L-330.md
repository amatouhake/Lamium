# L-330 Radar: mob icons that draw wrongly, then icons by default

Kind: Research, then Design
Status: Causes found from a sweep of every mob kind (2026-11-26); fixes and the open looks wait for the maintainer

Some mobs' icons on the radar do not draw correctly (maintainer
2026-11-13), so the radar keeps its Experimental badge.

## Decided
- If the icons can be made right, the radar's default changes from dots to
  icons (`map.radarFaces`, off today). The default changes only once the
  icons are confirmed in game (maintainer 2026-11-13).

## Known
The `radar_icon_probe` sweep (`aefddfb0`) built every data-driven
renderer's face once (214 renderers, 96 faces; logs/radar-sweep.*). The
horses the maintainer saw wrong on the radar look the same in the sheet,
so the faults are in building the face, not in drawing it.

| Mobs | What is wrong | Cause |
|---|---|---|
| hoglin, zoglin, goat | squashed or scattered face | part and cube rotations are ignored (hoglin's head is pitched 50°, goat's head cube 55°) |
| horse, donkey, mule, camel | grey blob, extra ears | worn tack is drawn (bridle, bits, reins); a horse also gets the mule's ears, which the game hides by its render controller |
| llama, trader_llama | a few stray pixels | the default skin is the carpet overlay (decor) |
| skeleton_horse, zombie_horse | a dot | the default skin is the empty armor layer |
| fox | 4x4, tiny | the default skin is the baby's sleeping texture |
| squid, glow_squid, silverfish, endermite, slime, magma_cube, ghast, happy_ghast, bee, strider, wither, tadpole, pufferfish, tropicalfish | a dot | the model has no part named "head" |
| camel, llama, cod, salmon, parrot, creaking | right, but hard to read | the front view of a long neck or a thin fish is a narrow strip |
| all | icon size and outline width differ | `faceTexelPixels`: a face with fewer texels gets bigger texels, and the one-texel outline grows with them |

Most renderers hold two geometries (adult and baby, or variants): the face
uses the first part named "head", and the default skin can belong to the
other one (the fox).

## Open
- A model without a head: which part to show (squid's body, the slime's
  cube, wither's middle head ...), or keep it a dot.
- Long necks and thin fish: crop to the head's front, a side view, or as
  they are.
- One texel size for every mob (even outline, sizes follow the models)
  against today's (small faces enlarged, outline thicker).

## Next
Fixes that make the icon match the model, pure first in `MapFaces.h` with
tests, then checked in game: rotations, tack and per-kind parts left out,
the textures of llamas, the skeleton and zombie horses and the fox. They
wait for the maintainer's go-ahead with the Open choices.
