# L-185 Instantly load a schematic into the world when cheats allow it

Kind: Design, then Research (strong model)
Status: Open, not approved for implementation or release

Explicitly materialize a whole chosen placed schematic in the world, like
the game's structure-block Load action, instead of building ghost cells by
hand. User feedback 2026-10-14.

## Decided
- Never silently modify the world, take a client-side visual as proof of
  server acceptance, or bypass permission checks.

## Open
Exact permission/capability checks for local and server worlds; block
replacement policy; entities, block entities and inventory data; size and
loaded-chunk limits; placement transformations; failure and undo UX.
