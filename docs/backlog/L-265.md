# L-265 Schematic placement assist: place the ghost's block in its state

Kind: Research, then Ready (strong model)
Status: Research done in a local world (2026-11-28); building is next

A mode in which using a block on a ghost places the schematic's block there
in the schematic's state. The contract (behavior, planned code, what the
traces found) is [PLACEMENT-ASSIST.md](../PLACEMENT-ASSIST.md); this file
keeps the build order.

## Decided
- Everything in PLACEMENT-ASSIST.md "Behavior" (maintainer 2026-11-28):
  faked look for one placement, first ghost on the ray clicked from a real
  neighbor at a chosen click, auto pick, toggle + HUD + settings row,
  holding use keeps placing, a toast says why nothing was placed.
- From the fifth trace: faked placements need no rate limit when the move
  input is turned with the look; the trigger for a ghost with air behind is
  `GameMode::useItem`; `getPlacementBlock` with the relative click chooses.

## Open
- The click while use is held: `buildBlock` took another click in 33 of
  77 held placements. Step 3 needs a source that ignores the build in
  progress (or rewrites the transaction and keeps the client's prediction
  in step); to settle while building.
- Maintainer: the lines marked (proposed) in PLACEMENT-ASSIST.md.
- Blocks other than stairs, and a dedicated server (step 6).
