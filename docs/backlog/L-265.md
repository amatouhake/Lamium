# L-265 Schematic placement assist: place the ghost's block in its state

Kind: Design / Research (strong model)
Status: Open, not started; no release target

A mode in which using a block on a ghost cell places the schematic's block
there with the schematic's facing and states (maintainer 2026-10-26, while
deciding L-263).

## Decided
- Do not change gameplay packets beyond what the player could do by hand
  without a separate decision.

## Open
- Whether to do it at all.
- Which states the player's own placement can produce (facing from look
  direction, half, slab type) and which would need a faked look or a
  server-visible trick; what servers and anti-cheat accept.
- How it relates to the vanilla place input and to L-263 (it reuses L-263's
  "bring the block into the hand" step); refusal when the block is not
  carried.
