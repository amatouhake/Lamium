# L-265 Schematic placement assist: place the ghost's block in its state

Kind: Research, then Ready (strong model)
Status: Main choices agreed (2026-11-28); the fourth experiment is next

A mode in which using a block on a ghost places the schematic's block there
in the schematic's state. The contract (behavior, planned code, what the
traces found) is [PLACEMENT-ASSIST.md](../PLACEMENT-ASSIST.md); this file
keeps the build order.

## Decided
- Everything in PLACEMENT-ASSIST.md "Behavior" (maintainer 2026-11-28):
  faked look for one placement, first ghost on the ray clicked from a real
  neighbor at a chosen click, auto pick, toggle + HUD + settings row,
  holding use keeps placing, a toast says why nothing was placed.
- Before the rate and movement are fixed, one more experiment (maintainer
  2026-11-28): placements with a faked look in a row at shorter intervals,
  and the move input turned with the look while walking and sprinting.

## Open
- Step 1 answers: the shortest interval between faked placements without
  a pull-back; whether turning the move input removes it; the trigger for
  a ghost with air behind; whether `getPlacementBlock` matches the server.
- Maintainer: the lines marked (proposed) in PLACEMENT-ASSIST.md.
- Blocks other than stairs, and a dedicated server (step 6).

## Next
1. Experiment (`placement_fake`): faked placements in a row at 1, 0.5,
   0.25 s and every tick, each interval with the move input turned and
   untouched (the variant named by the stair type held; inside the
   interval nothing is placed); every auth position logged for 20 ticks
   with the step along the heading, and the server's movement correction
   if it can be hooked. Read-only: `getPlacementBlock` beside each
   `useItemOn` (furnace, door, trapdoor, slab, log), and what fires on a
   use press with no block in reach (`GameMode::useItem`, FakeOffhand's
   `BuildAction`, PeriodicInput's use handlers).
2. `AssistPlan.h` with tests: neighbors, faces, clicks and looks to try,
   no-fake candidates first.
3. `PlacementAssist.cpp`: trigger on the ghost ray, hold vanilla, choose by
   `getPlacementBlock`, bring to hand, fake when needed, `buildBlock` with
   the hit result set, read the placed block back; capability-gated,
   GAME-UPDATES and LIFECYCLE lines.
4. Settings row, toggle action, HUD line, toasts, four languages; mockup
   only if the row or HUD line needs a look decision.
5. Remove the `placement_fake` experiment; both trace options off.
6. In game: stairs, slabs, logs, furnaces, doors and trapdoors on a local
   world, then a dedicated server (pre-release checks).
