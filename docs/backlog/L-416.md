# L-416 Settings rows: names and placement made consistent

Kind: Design
Status: Open, not started (from L-342, rechecked in code 2026-11-28)

Rows that say the same kind of thing in different ways, found by the
2026-11-14 review and still true in code on 2026-11-28.

## Open
- "Schematics" is both a category (`section.schematic`) and the pinned
  opener (`nav::schematics`), with one name.
- The Map page has two switches named "Waypoints": the feature row and the
  map marks child (`mapMarkWaypoints`).
- "Hide while Debug View is open" is three rows under two headings in two
  wordings (Info HUD and Target under Debug View, the minimap under Map).
- Debug View alone keeps text shadow and background as rows
  (`information.debugShadow`, `debugBackground`); the other HUD elements
  moved them to the layout editor.
- Sibling rows named unevenly: "Show schematic information" beside "Icon"
  and "Health" in Target Info.
- Distances said five ways: "Show up to", "Ghost outlines up to", "Range",
  "Display distance", "Up to the render distance".
- Small integer ranges: a stepper for Clicks 1-10 (step 0), a slider for
  row height 9-16 (step 1); the rule is in `SettingsTableView.cpp`.
- Game HUD parts: the rows order chat, scoreboard, paper doll, boss bars;
  `placedElements` and the editor order them otherwise.

## Next
Agree the wording and placement rules with the maintainer (a mockup where
it helps); then a Ready item. Strings change in all four languages.
