# L-344 English Search does not find enchanted books by enchantment name

Kind: Bug (against the player's expectation), Research, then Design for the scope.
Status: Open, not started. Reported by the maintainer while working on L-170 (noted before 2026-11-14).

With English Search on, typing an enchantment's English name ("protection",
"knockback") in the Creative search field does not find the enchanted books
that carry it.

## Decided
- English Search only adds matches, never hides what vanilla finds; a query
  matches when every word is in the item's English display name or its
  identifier without the namespace (L-130, see its record).

## Open
- Cause: an enchanted book's English display name is "Enchanted Book" and
  its identifier `enchanted_book`, so the enchantment names are outside what
  L-130 matches. Confirm that this, not a failing lookup, is why.
- Whether matching should extend to the enchantments an item carries (its
  stored enchantments' English names), for books only or for every
  enchanted item, and in which screens (Creative search, recipe book).

## Next
Confirm the cause in `src/features/inspection/EnglishSearch.cpp`; then agree
the scope with the maintainer before building.
