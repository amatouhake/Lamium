# L-408 Recipes: find enchanted books by their enchantments in English

Kind: Design
Status: Open; to start from a design conversation (maintainer 2026-11-25)

With English search on, Creative search finds an enchanted book by its
enchantments' English names and ids ("protection", "fire_aspect"; L-344).
The item list of L-359 Material plan across features does not: a plain word
matches the name as shown, the id and the English name, and an enchanted
book's English name is only "Enchanted Book". In Japanese `$ダメージ` finds
it through the tooltip text, but typing the game language each time is a
chore (maintainer).

## Decided
- The item list's search syntax (L-377 Search syntax and a key for the
  search field: words, `-`, `|`, `"…"`, `#`, `$`, `@`) is sound and is not
  reworked for this (maintainer, 2026-11-25).

## Open
- A: plain words also match a book's stored enchantments' English names and
  ids, as Creative search does (English search on).
- B: a sign of its own for enchantments, in English and the game language,
  leaving plain words as they are.
- C: with English search on, `$` also reads the tooltip in English.
- Books only, or other enchanted items (tools, armor) too?

## Known
- Creative's match: `src/features/inspection/EnglishSearch.cpp` reads a
  book's stored enchantments (`Enchant::mDescription` as an `enchantment.`
  key, and `mStringId`).
- The item list's match: `src/features/recipes/ItemSearch.h` (name, id,
  English name, tags, tooltip per item), filled in `ItemList.cpp`.
