# L-418 Screens: small behavior differences

Kind: Design
Status: Open, not started (from L-342, rechecked in code 2026-11-28)

Behavior that differs between Lamium's screens for no reason, found by the
2026-11-14 review and still true in code on 2026-11-28.

## Open
- A waypoint's name is saved when editing ends (`finishNumber`); a
  shape's at once (`shapes_view::applyName` every frame).
- Block highlight: Remove on the left asks twice; a result row on the
  right toggles at one click (`HighlightView.cpp`).
- HUD layout ignores a failed save (`HudEditor.cpp`); the settings table
  reports one.
- HUD layout's idle panel registers only its two buttons, so a click on
  the panel falls through to the element behind it.
- The Waypoints and Schematics tools' top-right switch is the feature's
  switch but reads "Show all" (Shapes says `shape.drawAll`).
- A key of a switched-off feature: Schematic keys toast "schematic.off",
  Sort returns silently. Needs one rule first.

## Next
The failed save and the click-through are bugs to fix as they are; agree
the rest with the maintainer.
