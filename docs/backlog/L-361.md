# L-361 Brewing in the recipe view

Kind: Research
Status: Open, not started

A potion has no recipe in the recipe view: the client's recipe table, which
[L-359](L-359.md) reads, does not hold brewing (seen in game 2026-11-18).

## Known
- The table read today is `Recipes::mRecipes` (GAME-UPDATES.md); potion
  mixes are kept elsewhere and the SDK headers give them no layout.
- The list already tells potions apart by aux, so a recipe can name them.

## Open
- Where the client keeps the mixes and container mixes, whether a server
  sends them, and whether they can be read without a hook.
- How a brewing step is laid out in the view (the stand's slots, the
  blaze powder that is fuel) and whether a plan follows it.

## Next
Search the SDK headers for the potion mix types and read them in a trace
build.
