# L-183 Disregard selected schematic check mismatches

Kind: Design (strong model)
Status: Per-state version built (`10325a18`), not working as meant; being redesigned over the whole Schematic feature (2026-11-15)

Leave chosen expected-vs-actual differences out of the check results (a
circuit under construction, a deliberate change, an error in the file).
The schematic file and the placed blocks do not change; the strict
comparison stays available.

## Decided
- Stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning keeps it; kept across rejoining. Older
  builds that save the placement may drop it (2026-11-06).
- A visible count with a list to undo one or all; stale entries are not
  applied; the number is capped. No "temporarily" in the wording.
- Ignored state differences count as matching (2026-11-15).
- Maintainer 2026-11-15, after the mockup `docs/demos/schematic-ignore.html`:
  - Uses vary by player, so the design covers what x where as a whole:
    what (one state / the whole block / block entity data) x where (this
    cell / selected cells / the same block in the placement / every
    placement, the last being today's Check switches).
  - A cell ignored as a whole block is not counted, like extras' "do not
    count".
  - Keys and the radial menu do the simple thing: ignore or un-ignore the
    looked-at cell as a whole block. Finer choices are made in the
    Schematics screen.
  - A fully ignored row stays in its own kind (wrong state, wrong block),
    dimmed; no separate "Ignored" divider.
  - The Ignored button is hidden while there are no entries.
  - Ignoring several at once uses L-190's list selection, built first.

  - First scope (what x where): whole block in this cell (keys, radial
    menu, Check row) and in selected cells (after L-190); one state in this
    cell (the per-state build, fixed), in selected cells (after L-190) and
    on every same block in the placement (e.g. all levers' powered). Not
    now: whole block on every same block or every placement; block entity
    data per cell. Every placement stays today's Check switches.

## Open

  detail pane, the ignored list, keys and radial menu), with today's Check
  switches and extras' "do not count" beside it.

## Known (the per-state build, `74941fa7`)
- An "Ignore" button per differing state on the selected wrong-state row;
  an entry names cell, file block and state key (any value passes); 64 per
  placement (1 MB document limit, tested); block entity rows, shulker
  openings and cells expecting air cannot be ignored.
- Seen in game 2026-11-15: ignored rows hard to tell apart, "Ignored: 0"
  shown with nothing ignored, and an ignored difference still in the Check
  tab, the Schematic HUD and the nearest-mistake key.
