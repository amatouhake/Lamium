# L-183 Disregard selected schematic check mismatches

Kind: Design (strong model)
Status: On branch `l-190-waypoint-selection`; follow-ups to the game check not seen

Leave chosen expected-vs-actual differences out of the check results (a
circuit under construction, a deliberate change, an error in the file).
The schematic file and the placed blocks do not change; the strict
comparison stays available.

## Decided
- Stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning keeps it; kept across rejoining. Older
  builds that save the placement may drop it (2026-11-06). At most 64 per
  placement, places and rules together; stale entries are not applied. No
  "temporarily" in the wording.
- Maintainer 2026-11-15 after using `41ace47e` (mockup v4): two kinds. A
  place (one cell, extras too; key, radial menu, Check rows): in no count
  and no material, its ghost stays. A rule, block type x item ("Lever:
  Powered"), on every such block of the placement: counts as matching.
  Items are block states and compared block entity fields, never told
  apart. One state on one cell is dropped (saved ones stale, not widened).
  Every-placement switches stay in the Check settings.
- Check list: one of All / Wrong block / Wrong state / Not placed (All takes
  not placed; mistakes first, nearest first), no counts, kept while the game
  runs; extras are wrong blocks (the "Extra blocks" setting stays). Rows:
  kind square (the filters' squares are the legend), no kind word, no
  position; cut names and tags in full on hover. The pane split stays shared.
- Ignoring is a yes/no beside the kind: hollow square and framed tag 場所を
  無視 / 違いを無視, none when only some items are ignored.
- Selected row: the kind named; "Differing items (Lever)", each "Ignore on
  all levers" (short "Ignore on all") or "Ignored on all levers" with Undo;
  a place's items without buttons, noted as not counted. Item lines that do
  not fit scroll with the wheel or the lists' bar (preview fixed, top on a
  new pick), named as on the target card. Actions: Show in world, Ignore /
  Stop ignoring this place. Several rows: Show in world, 場所を無視,
  無視をやめる; no "rows"; the preview marks every selected cell.
- "Ignore settings" ends the right pane's top line in every state, pressed
  while open, the name cut before it (the filter row keeps the filters). It
  turns the tab into its ignore view (again or Esc returns): "Ignored
  places" and 違いを無視できるブロック (Materials order) left, marked in the
  preview; a place's stop button or a block's items right ("pick a place or
  a block" first); stale dimmed; two-press Undo all. Not in Materials (L-116).
- "Place" everywhere: key 見ている場所の無視を切り替え, menu 見ている場所を
  無視 ("Ignore looked place"), toasts, the card 設計図: 場所を無視中.

`namesTop`, `countW`, `PaneScroll.h`, `stateLabel`.

## Chosen without asking
- A cell not counted leaves the materials whatever is there; changed
  entries keep the rows, counts say "counting" until the next pass (seen
  in game 2026-11-15, `41ace47e`).
- Item ids: a block state's name, or `#` + the field's compound and key
  (`#FrontText.Text`, `#note`), `#instrument`, `#opening`. A block's items:
  its palette states, then the compared fields of its block entities
  (respecting the sign text and block entity switches), plus any item
  ruled or differing now (waterlogging appears only then).
- Materials order: by the Materials tab line of the same name (it reorders
  as blocks are placed), other blocks after by name.
- English "Ignore on every Lever" / "Ignored on every Lever" (block names
  cannot be pluralized); the cap toast counts places and differences.
- Old one-state entries show under Ignored places tagged "Old form, not
  applied", removable with Stop ignoring; Undo all removes them too.
- All tints not-placed cells in the preview too; the ignore view's preview
  shows no kind tints and its filter row is empty. Several rows list names
  only (no "->") and keep the selection on a preview click. Action-row
  buttons widen for a long label.
