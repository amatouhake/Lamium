# L-183 Disregard selected schematic check mismatches

Kind: Design (strong model)
Status: Built on branch `l-190-waypoint-selection` (`41ace47e`), checked in game; design reopened 2026-11-15

Leave chosen expected-vs-actual differences out of the check results (a
circuit under construction, a deliberate change, an error in the file).
The schematic file and the placed blocks do not change; the strict
comparison stays available.

## Decided
- Stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning keeps it; kept across rejoining. Older
  builds that save the placement may drop it (2026-11-06).
- Undo one or all; stale entries are not applied; at most 64 per placement.
  No "temporarily" in the wording.
- Still standing from v2 (2026-11-15): a cell not counted is out of every
  count and the materials, like extras' "do not count", and keeps its
  ghost; an ignored difference counts as matching. Keys and the radial menu
  toggle the looked-at cell of the selected placement ("Show placement"
  moved to Placement); the target card says "Schematic: Whole block
  ignored". Extras (air in the file) get no per-cell entry.

## Built
- `CheckIgnores.h` (kinds, list, saved form, staleness, `judgeIgnores`) and
  one counting rule in `Verify.h`/`Verification.h` that totals, progress,
  materials, HUD, the nearest-mistake key and marks all use.
- Check tab row and several-row actions, "Ignored: N" list with Undo, the
  action `ignorelookedblock` (appended, unbound) and its menu item.

## Chosen without asking (kept unless the new model changes them)
- A cell not counted leaves the materials whatever is there. Changed
  entries keep the rows; counts say "counting" until the next pass. English
  menu label "Ignore looked block" (fits the ring at a small GUI scale).
- Seen in game 2026-11-15 (`41ace47e`): all of the above works.

## Next
Maintainer 2026-11-15 after using `41ace47e` (all recommendations taken);
discussed one part at a time (mockup v3 was set aside: it did not start
from today's screen); the next mockup is Japanese, made in that discussion:
- Two kinds only. "Do not count this cell" (today's whole block; key,
  radial menu, Check rows, ghosts too). "Ignore a difference in this
  placement": block type x item ("Lever: Powered", "Sign: Text"), on every
  such block of the placement. Items list block states and the compared
  block entity fields alike; players never see which is which.
- Dropped: one state on one cell; saved ones show as stale, not widened.
- Rules can be made before anything differs: the ignore screen lists the
  file's blocks (materials order), each opening to its compared items as
  toggles. A Check row's "Ignore this difference" adds the same rule.
- The button is always there, "Ignore settings" with no count or colon.
  The screen has two headings, "Cells not counted" and "Ignored
  differences"; stale entries sit dimmed under their heading.
- Every-placement switches stay in the Check settings.
- The Check list's filters (maintainer 2026-11-15, after reading today's
  layout): pick one of All / Wrong block / Wrong state / Not placed (All
  replaces Mistakes and takes not placed too, mistakes first, nearest
  first); extras join Wrong block (row kind and the right pane's count; the
  placement's "Extra blocks" setting stays); no counts on the filters; the
  choice is kept while the game runs, not saved.
- Ignoring is a separate yes/no, not a kind: an ignored row keeps its kind,
  its place and its difference in every filter, so a mistaken ignore is
  undone where it is; no Ignored filter (a "hide ignored" switch only if
  they crowd the list). The row says why (candidate: hollow kind square, a
  framed "Not counted" / "Difference ignored" tag; the rule's name in the
  detail pane); the exact look is settled in the mockup.
- The selected row (2026-11-15): each differing item (heading "Differing
  items (Lever)") keeps its difference and has one button naming its reach,
  "Ignore on all levers" (short form "Ignore on all" when the name does not
  fit); ignored, it reads "Ignored on all levers" with Undo. The cell's
  button is "Ignore this place" / "Stop ignoring this place"; extras get it
  too (they are Wrong block now). Several rows: Show in world, "Ignore the
  selected places", "Stop ignoring them" only; no item ignoring and no
  "rows" in the UI. Tags and fine wording are settled in the mockup.
- L-190 merged without the Check list's selection, which lands with this
  item; announce multiple selection (FEATURES.md, README) at that merge.
