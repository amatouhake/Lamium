# L-183 Disregard selected schematic check mismatches

Kind: Design, after 0.5.1
Status: Rules mostly agreed; two proposals to settle before building

While building redstone and other stateful structures, exclude selected
expected-vs-actual differences from the check results. A block with a
different powered/open/extended state can be intentional during
construction; the schematic file and the placed blocks do not change. This
is check-result suppression, not hiding the ghost or relaxing every
BlockState comparison. The original strict comparison stays available.

## Decided
Maintainer 2026-11-06:
- The choice persists across rejoining (no unsaved first version). It is
  stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning the placement keeps it. Older builds
  that save the placement may drop the key.
- The unit is one difference on one cell (this cell's `powered`), so
  another block there still shows as a mistake.
- A count of what is ignored stays visible, with a list to undo one or all.
  Entries the structure no longer has are ignored; the number is capped.
- The word "temporarily" goes from the feature's wording.

## Open
Proposed, to settle before building:
- Ignored differences count as matching in the totals.
- The choice is made from the Check list's row first.
