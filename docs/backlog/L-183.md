# L-183 Disregard selected schematic check mismatches

Kind: Design (strong model)
Status: Built on branch `l-190-waypoint-selection`, not checked in game

Leave chosen expected-vs-actual differences out of the check results (a
circuit under construction, a deliberate change, an error in the file).
The schematic file and the placed blocks do not change; the strict
comparison stays available.

## Decided
- Stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning keeps it; kept across rejoining. Older
  builds that save the placement may drop it (2026-11-06).
- A visible count with a list to undo one or all; stale entries are not
  applied; at most 64 per placement. No "temporarily" in the wording.
- Maintainer 2026-11-15, mockups `docs/demos/schematic-ignore.html` and
  `schematic-ignore-v2.html` (every recommendation accepted):
  - What x where as a whole: what (one state / the whole block / block
    entity data) x where (this cell / selected cells / every same block in
    the placement / every placement, the last being the Check switches).
  - First scope: whole block in a cell (key, radial menu, Check row) and in
    selected cells; one state in a cell, in selected cells and on every same
    block of the placement. Not now: whole block on every same block or every
    placement; block entity data per cell.
  - Two results only: a whole block is left out of every count, like extras'
    "do not count"; an ignored state counts as matching.
  - An ignored row stays in its own kind, dimmed, with a tag; no "Ignored"
    divider. The Ignored button is hidden with no entries and reads
    "Ignored: 0 (N stale)" when only stale ones remain.
  - Keys and the radial menu do the simple thing: ignore or un-ignore the
    looked-at cell of the selected placement as a whole block. "Show
    placement" moves to Placement; "Ignore the looked-at block" joins Show
    and check (6 + 6). The target card says "Schematic: Whole block ignored".
  - An ignored cell not yet placed keeps its ghost and leaves the materials
    list. Extras (air in the file) get no per-cell ignore.
  - Several rows use L-190's selection; keys that not all rows share list
    each key with its row count ("Powered · 3 / 5 rows").

## Built
- `CheckIgnores.h`: entry kinds, the list (cap, all-or-nothing bulk add),
  saved form (`"x,y,z block"`, `"x,y,z block state"`, `"* block state"`;
  the per-state build's entries load as state here), staleness, the verdict
  (`judgeIgnores`), the Ignored button's look and list order, the selection
  pane's helpers. `Verify.h`/`Verification.h`: `countedState`, `Tally::add`
  with the verdict, `countsAsMistake`, `nearestMistake`; the totals, Placed
  progress, materials, HUD, nearest-mistake key and in-world marks all go
  through them (`tests/CheckIgnoresTests.cpp`).
- Check tab: the row's whole-block toggle in the action row; per state
  "Ignore here", "Ignore on all N" or Undo (for an every-same-block entry
  "Undo (all N)"); "Ignored: N" at the right edge with the list (every same
  block first, then nearest cells, stale last; no scrolling, "N more").
- Several rows: Show in world (marks up to 64 cells), Ignore whole blocks,
  Un-ignore (the rows' own entries only), disabled when they change nothing;
  the states with their row counts and "Ignore on N rows" or Undo.
- Action `ignorelookedblock` (appended, unbound) and the menu item.

## Chosen without asking (least surprising)
- One key `ignored` with three string forms instead of a new key, so the
  per-state build's entries need no conversion.
- A whole-block ignored cell is left out of the materials whatever is there
  (not only when not placed): "not counted" everywhere.
- Changing only the entries keeps the Check rows usable (not "counting")
  until the next pass; the state lines follow the live entries at once.
- The card shows no row for a cell whose differences are all ignored (it
  reads as correct) and leaves ignored differences out of a wrong state.
- English menu label "Ignore looked block" (the longer one widened the ring
  past a small GUI screen); the Hotkeys name is "Ignore the looked-at block".

## Known
- The per-state build's in-game failure (ignored differences still counted)
  was not traced in its code; counting now runs through one tested rule.
