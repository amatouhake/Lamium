# L-183 Disregard selected schematic check mismatches

Kind: Ready (strong model)
Status: Built, not checked in game

While building redstone and other stateful structures, exclude selected
expected-vs-actual differences from the check results. A block with a
different powered/open/extended state can be intentional during
construction; the schematic file and the placed blocks do not change. This
is check-result suppression, not hiding the ghost or relaxing every
BlockState comparison. The original strict comparison stays available.

## Decided
Maintainer 2026-11-06:
- The choice persists across rejoining (no unsaved first version). It is
  stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning the placement keeps it. Older builds
  that save the placement may drop the key.
- The unit is one difference on one cell (this cell's `powered`), so
  another block there still shows as a mistake.
- A count of what is ignored stays visible, with a list to undo one or all.
  Entries the structure no longer has are ignored; the number is capped.
- The word "temporarily" goes from the feature's wording.

Maintainer 2026-11-15:
- Ignored differences count as matching in the totals.
- The choice is made from the Check list's row first.

## Choices made while building (unattended, 2026-11-15)
Least surprising readings, open to change:
- "From the row" is an "Ignore" button beside each differing state of the
  selected wrong-state row in the Check pane (the unit is one state, and a
  row can list several).
- An entry names the cell, the file's block there and the state key, not
  the values: any value of that state passes. Ignorable: block states, the
  on/off pair's "lit"/"powered", and waterlogging. Not ignorable: block
  entity rows (their names are translated labels), a shulker box's opening,
  cells expecting air.
- The cap is 64 per placement, so 64 full placements stay under the
  placement document's 1 MB read limit (tested).
- The list replaces the counts while "Ignored: N" is pressed; entries that
  do not fit show "N more" (no scrolling). Stale entries stay listed, are not
  counted, and are removed only by Undo.
- A wrong-state row now lists a waterlogging difference beside its other
  states (before, only when nothing else differed), so ignoring the block's
  states cannot pass a cell whose water is wrong.
- The Check list's selection now follows its cell when the rows change.
- The inline Ignore and Undo buttons are plain `drawButton`s 10 units high
  to fit the state lines (the action row's are 12); "Undo all" is the shared
  destructive button; "Ignored: N" is primary while its list is open.
- No path copies a placement, so nothing inherits ignores; a new placement
  starts with none.

## In game
- Ignore a lever's or door's state, see the row, HUD count and yellow mark
  go; rejoin, turn and move the placement: still ignored. Undo and Undo all.
