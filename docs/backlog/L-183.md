# L-183 Disregard selected schematic check mismatches

Kind: Design (strong model)
Status: Built on branch `l-190-waypoint-selection` (`41ace47e`), checked in game; design reopened 2026-11-15

Leave chosen expected-vs-actual differences out of the check results (a
circuit under construction, a deliberate change, an error in the file).
The schematic file and the placed blocks do not change; the strict
comparison stays available.

## Decided
- Stored per placement in its saved file, as an optional key in schematic
  coordinates, so moving or turning keeps it; kept across rejoining. Older
  builds that save the placement may drop it (2026-11-06).
- Undo one or all; stale entries are not applied; at most 64 per placement.
  No "temporarily" in the wording.
- Still standing from v2 (2026-11-15): a cell not counted is out of every
  count and the materials, like extras' "do not count", and keeps its
  ghost; an ignored difference counts as matching. Keys and the radial menu
  toggle the looked-at cell of the selected placement ("Show placement"
  moved to Placement); the target card says "Schematic: Whole block
  ignored". Extras (air in the file) get no per-cell entry.

## Built
- `CheckIgnores.h` (kinds, list, saved form, staleness, `judgeIgnores`) and
  one counting rule in `Verify.h`/`Verification.h` that totals, progress,
  materials, HUD, the nearest-mistake key and marks all use.
- Check tab row and several-row actions, "Ignored: N" list with Undo, the
  action `ignorelookedblock` (appended, unbound) and its menu item.

## Chosen without asking (least surprising)
- One key `ignored` with three string forms instead of a new key, so the
  per-state build's entries need no conversion.
- A whole-block ignored cell is left out of the materials whatever is there
  (not only when not placed): "not counted" everywhere.
- Changing only the entries keeps the Check rows (dimmed by the live
  entries); counts, HUD and the key say "counting" until the next pass.
- The card shows no row for a cell whose differences are all ignored (it
  reads as correct) and leaves ignored differences out of a wrong state.
- English menu label "Ignore looked block" (the longer one widened the ring
  past a small GUI screen); the Hotkeys name is "Ignore the looked-at block".

## Known
- Seen in game 2026-11-15 (`41ace47e`): everything listed works; the
  per-state build's still-counted difference did not recur.

  such block of the placement. Items list block states and the compared
  block entity fields alike; players never see which is which.

  state ignore. Saved one-cell state entries are not widened: they show as
  stale.
- Rules can be made before anything differs: the ignore screen lists the
  file's blocks (materials order), each opening to its compared items as
  toggles. A Check row's "Ignore this difference" adds the same rule.
- The button is always there, "Ignore settings" with no count or colon.
  The screen has two headings, "Cells not counted" and "Ignored
  differences"; stale entries sit dimmed under their heading.
- Every-placement switches stay in the Check settings.
- The Check list (decide in the same mockup, build may be split): one list
  with filter toggles Mistakes / Wrong state / Not placed / Ignored (all on
  but Ignored), no tabs; ignored rows show dimmed only with Ignored on.
