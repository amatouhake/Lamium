# L-325 Zoom: return to the set magnification on release

Kind: Ready.
Status: Built, not checked in game (the option checked in game at `10325a18`; on by default built since)

Today the wheel's magnification is kept for the next press (`ZoomState`:
`release` keeps the target; only a changed setting or `reset` returns to
it). Add an option under Zoom that makes every press start from the set
magnification. From issue #74 (2026-11-10).

## Decided
- Option "Reset on release" under Zoom. On for new installs; a settings
  file that already has the key keeps its value (maintainer 2026-11-15).
- Not taken from the same issue: easing on press and release, settings for
  animation speed, per-behavior toggles.

## Chosen while building
- A file without the key (written before L-325) also gets the new default,
  on; only a file that has the key keeps its value (2026-11-15).

## Tried
- Easing on press and release: tried and dropped 2026-10-06 (see
  `ZoomState::press`).
