# L-33 Mob growth and breeding states in the target card

Kind: Ready
Status: Decided 2026-11-17 (maintainer): states only; being built on `night/L-33`

The maintainer wanted the time until a baby mob grows up and the remaining
breeding cooldown in the target card (asked 2026-09-24). The client does not
have those times, so the card shows the states it has and says so.

## Decided
- The client actor has neither `AgeableComponent` nor `BreedableComponent`
  (probe 2026-11-12, `world_probe` build): it only receives the synced
  `Baby` and `Inlove` flags. Estimating from observed events is not
  accurate enough to show as a time.
- States only (maintainer 2026-11-17): the card already has "Age: Baby /
  Adult"; it adds "In love: Yes" while `ActorFlags::Inlove` is set (no row
  otherwise). The local server is not read.
- The target card's help says the time until a mob grows up or can breed
  again is not shown because the client does not have it.

## Next
Build on `night/L-33`, then check in game: feed two cows, look at one.

## Known
For a later server read (not chosen), SDK 26.60.4: `AgeableComponent::mAge`;
`BreedableComponent::mLoveTimer`, `mBreedCooldown`; the server level ticks
on its own thread, so a read would have to be queued onto it.
