# L-319 Item details: Work Penalty first, then the unshown rest

Kind: Feature; what remains is Design
Status: Built 2026-11-13 after 0.6.0 (not released) and checked in game; open choices, small fixes and unchecked cases remain

An item's tooltip tells what the client knows and the game does not print:
the anvil work penalty with its prior-use count first, then a suspicious
stew's effect, property values, the ID, tags and NBT. Maintainer's note
2026-11-07. Current behavior and decisions: [ITEM-DETAILS.md](../ITEM-DETAILS.md).

## Decided
- Direction (maintainer 2026-11-13): "as much about an item as can be
  shown"; no list of further details is decided.

## Open
- The enchantability wording ("Enchantability: 15"), if the setting's help
  text is not enough.
- On an unverified game version the work penalty line goes missing under
  the `EnchantOrder` capability, which belongs to Enchantment order, so
  nothing marks Item details as paused.
- The main switch's help says off leaves the game's own tooltip, but "Hide
  shulker box contents text" (Container previews) still applies. Reword the
  help or make the hiding follow the switch.
- Not built, each needs a source or a decision first: the anvil repair
  material, firework detail the game does not print, grindstone experience
  return.
