# L-111 Integration between features: remaining shared controls

Kind: Design
Status: Optional scope, nothing chosen for implementation or release

The required integration work shipped in 0.2.0 (2026-10-11; plan and checks
in BACKLOG-DONE.md). What remains is optional: a common Lamium radial menu,
looked-at selection and settings cross-links (C/D/E in
[INTEGRATION.md](../INTEGRATION.md)).

## Decided
- Keep independent feature lifecycles and shared parts that features
  register into; do not merge features. Keep display layers distinct from
  allowed-action regions.
- Tidy touched code separately from behavior changes, preserve
  per-capability fail-open, and check each step in game before the next.
- A menu needs an agreed demo first.

## Open
- One common opener versus per-feature openers.
- Maintainer input 2026-10-13: make spatial actions usable while working,
  without setting up a feature first. Candidate shared operations: a base
  point from the looked-at block or feet, two range corners, a Y boundary
  adjusted by the wheel, repeating the last adjustment. L-173 quick shapes
  and L-15 restrictions own their behavior; L-230/L-231 first address the
  schematic controls themselves.
- Input contexts, binding conflicts and UI weight, to check with the
  maintainer.
