# L-324 Map: custom blocks are drawn in a dirt-like brown

Kind: Research
Status: Open, not started (issue #76, accepted by the maintainer 2026-11-13)

On the minimap and world map, add-on blocks show brown instead of their own
color, while the game's map item shows the color of their
`minecraft:map_color` component (reported on 0.6.0, game 26.60, with steps:
an add-on with such blocks, a filled area, compare with a map item).

## Decided
- How Lamium colors a block (`Minimap.cpp`, `blockLook` / `blockColor`): the
  average of the top texture from `BlockGraphics`, times the biome tint; the
  game's `getMapColor` only when no texture color was found.
- The fix is the maintainer's choice once the cause is known.

## Open
- Hypothesis, not checked: for add-on blocks `BlockGraphics` hands back a
  default texture, so a color is found and it is the wrong one.

## Next
Reproduce with an add-on and read which texture path the block resolves to
(the map's diagnostics log the first texture loads). Then either fall back
to `getMapColor` for blocks whose texture is that default, or find the
block's real top texture.
