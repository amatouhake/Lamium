# L-368 Close the game's recipe book while the recipe view is open

Kind: Research
Status: Open, not started; may wait (maintainer 2026-11-20)

With the game's recipe book out, the inventory's window is wide, and the
recipe view covers all of it, so a view with few recipes has wide empty
sides. Six recipes a page are enough; more columns would not help when
there are few (maintainer 2026-11-20). The wish: while the recipe view is
open, the game's recipe book is closed so the window narrows, and it comes
back as it was when the view closes.

## Known
- Lamium reads whether the book shows from the `recipe_book` control's
  visibility (`ItemList.cpp`, `windowOf`); it never changes it.

## Open
- Whether the game's own toggle (the book's button on the inventory
  screen) can be pressed or called from Lamium, and what it changes: a
  saved option, the screen's state, or only the controls' visibility.
- Whether hiding the controls alone narrows the window or desyncs it.
- Restoring the book when the view closes, on focus loss and on leaving
  the screen (AGENTS rule 3), and whether a write is version-sensitive.

## Next
Search the SDK headers for the recipe book's toggle and its screen
controller handler; trace a press of the game's own button.
