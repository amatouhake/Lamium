# L-317 Forcing the Surface view leaves the minimap nearly useless in the Nether

Kind: Ready.
Status: Built and checked in game (`10325a18`); a key of its own for the Nether view agreed 2026-11-15, not built

With the minimap view forced to Surface (L-253), the Nether also uses the
surface view, so only the bedrock ceiling is visible and the minimap loses
almost all meaning there. Reported from play 2026-11-07; a player asked for
the cave view in the Nether and the surface view above ground (2026-11-15).

## Decided
Maintainer 2026-11-15:
- One more row under the minimap view: "Nether view": Same as others /
  Automatic / Surface / Cave, default Same as others. Existing settings
  keep today's behavior; the Nether's forced Surface stays possible for
  creative work under the ceiling.
- The Nether view gets its own action and key, set apart from the cave
  view's key; the cave view key changes only the cave view row (maintainer
  2026-11-15: no special cases in how keys work). Appended as a new action.
- No separate End row.

## Chosen while building
Unattended build 2026-11-15, least surprising where the decision was silent:
- The key never sets the Nether row back to Same as others; it cycles
  Automatic -> Surface -> Cave there. The toast is the same as elsewhere.
- Only the Cave view row shows the view key in the settings list.
