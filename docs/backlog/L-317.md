# L-317 Forcing the Surface view leaves the minimap nearly useless in the Nether

Kind: Ready.
Status: Open, not started; candidate (b) chosen 2026-11-15

With the minimap view forced to Surface (L-253), the Nether also uses the
surface view, so only the bedrock ceiling is visible and the minimap loses
almost all meaning there. Reported from play 2026-11-07; a player asked for
the cave view in the Nether and the surface view above ground (2026-11-15).

## Decided
Maintainer 2026-11-15:
- One more row under the minimap view: "Nether view": Same as others /
  Automatic / Surface / Cave, default Same as others. Existing settings
  keep today's behavior; the Nether's forced Surface stays possible for
  creative work under the ceiling.
- The view key cycles the view used in the current dimension: in the
  Nether with an override, the override.
- No separate End row.
