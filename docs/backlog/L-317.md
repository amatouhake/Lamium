# L-317 Forcing the Surface view leaves the minimap nearly useless in the Nether

Kind: Design.
Status: Problem recorded, solution deferred: no candidate is good enough yet.

With the minimap view forced to Surface (L-253), the Nether also uses the
surface view, so only the bedrock ceiling is visible and the minimap loses
almost all meaning there. Reported from play 2026-11-07; the maintainer's own
play agrees. Doing nothing is not the answer.

## Decided
- L-253's checked behaviour stands until a candidate survives the
  counterweight below.

## Open
- Candidates: (a) in the Nether only, a forced Surface falls back to
  Automatic; (b) the view choice set per dimension; (c) a roof-aware forced
  Surface (cave view while a ceiling is above the player), close to what
  Automatic already does, so it may only duplicate it.
- Counterweight: forced Surface has real uses in the Nether (creative work
  that breaks the bedrock ceiling and builds custom spaces). A fix that
  quietly erases the force there trades one complaint for another.
