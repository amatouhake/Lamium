# L-114 3D previews in the schematic screen

Kind: Research (strong model)
Status: Partly done: Files and Check tab previews shipped (0.1.8); the Check tab's mistake look, see-through emphasis and moving the zoomed view are open

A rotatable 3D preview of a file in the Files tab and of the selected
placement colored by verifier state in the Check tab (selected row lit).

## Decided
- Check tab layout A (SCHEMATIC.md "Check tab review"): chips drive the
  preview, wheel zoom held at the size that fits the box (the UI scissor
  does not clip the mesh), Shift+wheel peels layers from the side chosen
  when peeling starts, click to inspect (Files names the block; Check
  selects its row or checks the cell), the Check list keeps the nearest 2000
  of each kind. Drag turns it.
- The mistake look and see-through emphasis were decided in that review;
  they were deferred to the rendering work and not yet built.
- How it works (`Preview.cpp`, pure parts in `PreviewView.h`): visible
  blocks are tessellated in-world at a spot above the build limit (no real
  neighbor or light), moved to their cell, and drawn with the ghosts' block
  material into a scissored box. Block entities, entities and liquids are
  drawn. The UI pass keeps the first fragment and has no usable depth, so
  quads are sorted near to far for the view's octant, kept, and re-sorted
  only when the view turns (recolored when the check changes). Faces covered
  by an opaque block drawn on this path are dropped. Normals all point up
  and faces are darkened by direction. 3000 blocks built per frame, up to
  120000 visible.
