# L-377 Search syntax and a key for the search field

Kind: Design
Status: Open, not started

The item list's search takes words that must all be in an item's name or
id. Agreed in [L-371](L-371.md): a richer syntax and a key that puts the
cursor in the field.

## Decided
- To search by: leaving a word out, either of two words, an item tag,
  and the item's tooltip text (what `hoverLines` gives).
- A key, bound by default or not (decided here), puts the cursor in the
  search field on item screens.

## Open
- The characters (a leading "-" to leave out, "|" for either, "#" for a
  tag, "$" for the tooltip; quotes for a phrase) and how they read in
  Japanese input.
- Which tags the client can read for every item, not only those recipes
  name (research in the SDK).
- The cost of tooltip text for every listed item, and when it is read.
- The key's default (Ctrl+F was suggested) and its layer ([L-372](L-372.md)).

## Next
Research the tags and the tooltip cost; then a short proposal of the
syntax with examples.
