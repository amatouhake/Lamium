# L-351 One wording for press-again confirmations

Kind: Ready
Status: Built, not checked in game

Nine two-press buttons share the danger button's look but word the armed
state four ways ("Press again to delete", "Press again", "Again",
"Delete N?"; Japanese also mixes 削除 / 消す and one polite 戻します).

## Decided
Maintainer 2026-11-15:
- An armed button reads "Again: " + its own label, in every language
  ("Again: Delete", "Again: Delete 5", "Again: Reset category";
  「もう一度: 削除」「もう一度: 5 件削除」). Built once in the shared widgets so
  no screen words it by hand; short enough for narrow buttons.
- Things the player made or saved (waypoints, shapes, placements, saved
  data, the map cache) are "Delete" / 削除, not 消す; no polite forms.
- What a delete removes (Saved data's waypoint count and map size) moves
  out of the button into the text beside it.
- The rule goes into DESIGN.md.

## Built
`againLabel(label, armed)` in ListViewWidgets.h (key `confirm.again`) at
every press-twice button: Waypoints / Shapes / Schematics Delete, the world
map Delete and its context menu, settings map cache Delete, Saved data
Delete, the settings table's Reset, the HUD editor's Reset layout, the
schematic check's Undo all and the highlight list's Remove. The old armed
strings are gone. 消す became 削除 on Saved data and the map cache (buttons,
their toasts and the map cache help).

Choices made without asking:
- Saved data shows "{n} waypoints, map {size}" beside Delete always (dim,
  white while armed), and Delete is sized for its armed label so arming
  moves nothing.
- The schematic save prompt's Overwrite stays as it is: its armed state is
  a different control (a new label with the reason in the prompt), not a
  press-again button.
- No pure test: the helper only formats a translation; the translation
  test covers the placeholder.

Cut by the fixed widths (shown with "...", not measured in game): the
highlight list's Remove (40 units) in every language, and the settings
table's Reset (84 units) for "Reset category" and "Reset all keys" and
likely every Japanese and Chinese reset. Widening them is a layout choice
left open.
