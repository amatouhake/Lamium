# L-405 Client pointers kept across frames: change the rule or the code

Kind: Refactor
Status: Open; the choice is not made

AGENTS.md rule 2 says no game pointers are kept across frames. Five places
keep an `IClientInstance*`; nothing checks the rule.

## Open
- Write the client instance into rule 2 as the one exception (if it lives
  as long as the game does, which nobody has verified here), or fetch it at
  each use (`ll::service::getClientInstance()`, or the one a hook or render
  call is handed).
- Whether a script should flag a stored pointer to a game type.

## Known
- `src/features/camera/CameraSessions.h` (`std::atomic<IClientInstance*>
  client`), `src/features/schematic/SchematicActions.cpp` (`adjustClient`),
  `src/features/map/WorldMap.cpp` (the screen's state, `client`),
  `src/features/interaction/PeriodicInput.cpp` and
  `src/ui/SettingsScreen.cpp` (`client`, which `screen::client()` hands to
  the views).
