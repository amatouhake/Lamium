計画の数の見せ方（L-370）

左の帯の「今/必要」と、窓の数の列と棒の間隔を比べる。帯の案と窓の案は別々に選べる。帯と窓の上のタブで「集める物」「作る物」を切り替えられる（連動）。

言語

見るところ

  • 帯 a：今の書き方。作る物も全行「今/必要」にそろえた形（決定済み）。完了はチェック。
  • 帯 a2：今の数を主役に、「/必要」を小さく薄く。桁の多い行でも左の数が目に入るか。
  • 帯 b：数を 1 つにする。集める物は「あと何個」、作る物は「あと何個作るか」。今作れる数や所持は帯の行に重ねたときのツールチップへ。
  • 帯 c：必要の数を右に出し、その左に進み具合の小さな棒。窓と同じ道具立て。
  • 窓 A：所持・必要・棒の 3 列を同じ間隔で並べる。棒の列にも見出しの位置を取る。
  • 窓 B：「所持 / 必要」を 1 列にまとめ、棒を同じ間隔で横に置く。帯 a と同じ書き方。

決めたいこと

  • 1. 帯の数：a / a2 / b / c。
  • 2. 窓の列：A / B（今のままも選べる）。
  • 3. 帯と窓で書き方をそろえるか（例：帯 a と窓 B、帯 c と窓 A）。
