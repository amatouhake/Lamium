Ignoring check differences: the first scope, end to end

The agreed first scope. Whole block in one cell (key, radial menu, Check row) or in selected cells. One state in one cell, in selected cells, or on every same block of the placement. One example drives every panel: ignoring something updates the list, totals, HUD and world. UI text is Japanese, as the game shows it. Strings tagged new do not exist yet. Block art and positions are placeholders. Click a row. Ctrl+click adds rows, Shift+click takes a range, Ctrl+A selects all and Esc clears (click the screen first). The click-mode buttons below do the same on touch.

1. One row selected: the detail pane

  • Whole block: ブロックごと無視new sits in the action row next to ワールドで示す. It works on wrong-block, wrong-state, block-entity and not-placed rows. On an ignored row it reads 無視を戻すnew. The cell then leaves the totals: the "/ total" drops by one, as extras' 数えない does. The row stays in its kind and place, dimmed, with a ブロック無視new tag.
  • One state: each line under 違う状態 has ここで無視new and 全 N 個で無視new. N counts the placement's blocks of this kind. The second button covers every lever's 動力, now and later. An ignored line stays in place, dimmed, and its tag says which entry covers it: 無視中new or 無視中 · 全 12 個new. 戻す removes that entry. On a 全 N 個 line, 戻す reads 戻す（全 12 個）new, because it frees every lever.
  • When every differing state of a row is ignored, the row counts as correct. It stays in its kind, dimmed, with a 状態無視new tag. The total does not change. A row with only some states ignored is still a yellow, counted mistake.
  • No per-state buttons on block-entity rows (the sign), on a shulker box's opening, or on cells expecting air (Known in L-183). The sign can still be ignored as a whole block. The extra-block row (file: air) gets no whole-block button here: see question 3.
  • Ignoring a whole block keeps that cell's state entries. They show dimmed under it, so 無視を戻す restores the state ignores that were there before.

2. Several rows selected: the selection pane (L-190)

  • The pane shows a count header (N 行を選択new) and the names in list order, as plain lines up to what fits, then ほか N 件. All selected rows share one highlight. The bulk actions sit where the single pane's buttons sit: ワールドで示す (marks every selected cell), ブロックごと無視, 無視を戻す. A button that would change nothing is disabled.
  • States when the rows do not share a key (decided here): the pane lists every differing state that occurs in the selection, with how many rows have it, for example 動力 · 3 / 5 行. Its button 3 行で無視new adds one "here" entry on each of those rows. The other rows are left alone. A key shared by all rows needs no special case. A key already ignored on all its rows is dimmed, with 戻す.
  • "Every same block" is not offered here: the selection can mix block kinds. It stays on the single row's state line.
  • 無視を戻す removes the selected cells' own entries (whole block and "here" states). A 全 N 個 entry is not removed, so a lever it covers stays dimmed. Its tag says why.
  • Cap: a bulk action that would go over 64 entries changes nothing. The footer shows the existing message 無視できる違いは配置ごとに 64 件まで. Try "Fill to 62 entries" and then ignore three rows.

3. In the world: key and radial menu

Look at

One key (見ているブロックの無視を切り替えnew, unbound by default) and one menu item do the same thing: they ignore the looked-at cell as a whole block, or un-ignore it. The target is a ghost, or a real block in a placement cell, picked as the target card picks. Toastsnew: ブロックごと無視: 石（-97, 86, -41） and 無視を戻しました: 石. On a correct block: 正しく置かれています (existing). Off the placement: 設計図のブロックを見ていませんnew. When full, the existing cap message. Finer choices (one state, every same block) stay in the screen.

Choice 1. A (recommended): an ignored not-placed cell keeps its ghost, so the same key can still hit it to un-ignore. Ignoring changes the check, not the file. Cost: a part you will never build stays drawn. B: the ghost is hidden, which looks cleaner. Cost: nothing is left to look at, so un-ignoring needs the screen. Real ignored cells lose their red or yellow box under both options.

Radial menu, 表示と照合

4. The Ignored list

  • The 無視: N button sits right of the action row and counts the entries that apply. It is hidden while the list is empty. Pressed, it opens the list in place of the counts. Entries come in three kinds. Each names the file's block:
    全 12 個 · レバー · 動力new, -97, 86, -41　石 · ブロックごとnew, and -98, 85, -40　レッドストーンリピーター · 向き.
  • Order: every-same-block entries first, then cells nearest first. 戻す on each line. すべて戻す takes two presses (もう一度押すとすべて戻す). Lines that do not fit end with ほか N 件, with no scrolling.
  • Stale: the file no longer has that block at that cell, or no block of that kind at all for a 全 N 個 entry. The line is dimmed with 設計図にない. It is not applied and not counted in N, but it keeps the button visible, so it can still be removed. All three kinds share the cap of 64.

5. Totals and the Schematic HUD

  • A cell ignored as a whole block is left out: it is in no count and the total drops by one, as with extras' 数えない. An extra block's 数えない does not change the total (the file has air there). Here it only drops 違う・余計.
  • Ignored states count as matching: 状態違い drops and 正しい rises, with the same total.
  • 最も近い間違い and the nearest-mistake key skip both kinds and fully state-ignored rows. A partly ignored row is still found. The HUD gets no "ignored" line: the count is on the Check tab's button.

  1. Choice 1, the ghost of an ignored not-placed cell: A drawn as usual (recommended: the key can still un-ignore it) or B hidden.
  2. Choice 2, the radial menu: A a 7th item in 表示と照合 (no other item moves) or B 配置を表示 moves to 配置, keeping 6 + 6 (recommended: keeps the five-or-six rule, and showing is a per-placement setting). Cost of B: one item moves from where it was learned.
  3. Extra-block rows (file: air): allow a per-cell ブロックごと無視, so one stray torch stops counting while the placement's other extras stay red? It would extend Known's "cells expecting air cannot be ignored", which was written for states. The mockup offers no button.
  4. Materials: should an ignored not-placed cell leave the Materials list (consistent with "not counted"), or stay, because the file is unchanged? Not drawn here.
  5. Key target: the selected placement only, like the nearest-mistake key, with other placements getting 設計図のブロックを見ていません? Or whichever placement owns the looked-at cell? The mockup assumes the selected one.
  6. Target card: add a dimmed line such as 設計図: ブロックごと無視new on an ignored cell, so the key's effect is visible up close? Not drawn as decided.
  7. Still open from v1: with only stale entries left, the button reads 無視: 0 while its list is not empty. Show the entry count in that one case, or accept it as rare?
