BACKLOG L-359 · レシピを見る画面 · モック 1（2026-11-17）

インベントリの横にアイテム一覧、そこからレシピを開く

1920×1080 と同じ割合です。ゲームのインベントリ画面の横に Lamium のアイテム一覧を出し、アイテムを押すとレシピ、右クリックで使い道が開きます。一覧は検索でき、ホイールか矢印でページを送れます。レシピの中のアイテムも押せます。ゲームの画面とアイテムは仮の絵で、レシピは見本として数十種類だけ入っています（棒、松明、チェスト、石レンガ、鉄インゴット、木材や石材の階段など）。計画の画面は次のモックで扱います。

このモックの決めごと

  • 一覧はいつも出ています。インベントリを開けば右に並び、検索欄に打てば絞り込まれます。
  • クリックでレシピ、右クリックで使い道。ホバー中に R / U でも同じです（キーは変えられる前提）。A でお気に入り。
  • レシピは作業場所ごとにタブ（作業台、石切台、かまど、溶鉱炉）。同じ場所に複数あれば矢印で送ります。
  • 「どれでも」の材料は数秒ごとにアイコンが替わり、ホバーすると全部の種類が格子で出ます。
  • レシピの中のアイテムを押すと、そのアイテムのレシピへ移ります。Backspace で戻り、Esc で閉じます。
  • ゲームのレシピブックをオンにすると、インベントリが右へ寄る分だけ一覧が細くなります。
  • アイテムを出す（チート）機能は入れません。

見てほしい所

  1. レシピの出し方。インベントリに重ねる（レシピ Mod でよくある形）か、左の空きに並べてインベントリを触れるままにするか。レシピブックがオンのときは空きが無いので重ねます。
  2. 左側の使い方。何も置かないか、お気に入りを置くか。計画を置く候補地でもあります。
  3. 検索欄の位置。一覧の下か上か。
  4. 一覧の中身。全アイテムを並べるだけか、「今作れる物だけ」などの絞り込みを最初から持つか（このモックには入れていません）。
  5. どの画面に出すか。インベントリ、作業台、かまど、チェストなど、アイテムを扱う画面すべてを想定しています。
