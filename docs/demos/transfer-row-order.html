左が今の設定画面（src/ から生成した行そのまま）、右が案です。案で変えた行には左端に水色の印が付きます。上の切り替えで「並び」「キーの順」「名前」を別々に試せます。

2026-11-24 · 決めること: 子 15 行の並び、各行のキー表記の順、同じ名前の 2 組を分けるか

確認したいこと

  • 並び: 案は操作の種類ごと（ホイール 4 → Alt + クリック 2 → ドラッグ 3 → 持ったまま 1 → 捨てる 5）。捨てるドラッグ 3 行は転送ドラッグと同じ順（スタックごと → 各スロットから1個 → 1個残して）です。この区切りと順でよいか。
  • キーの順: 案は「Ctrl → Shift → Alt → その他のキー（捨てるキー）→ マウス・ホイール」。Lamium のキー割り当ての並べ方（修飾キー、ほかのキー、マウス、ホイールの順）に合わせたものです。表示の順で、押す順ではありません（捨てるドラッグは今どおり Q を押したままでも Shift が先でも動きます）。Alt + Shift + クリックは「SHIFT + ALT + 左クリック」になります。
  • 名前: 「同種をすべて転送」「すべて転送」はホイール版と Alt + クリック版で同じ名前です。案では Alt + クリック版を「クリックした側から…」にします（ホイールは上下の向きへ、Alt + クリックはクリックした側から反対側へ動かす違いがあるため）。分けるか、キー表記があるので今のままにするか。
  • キー欄の「捨てるキー」はモックアップの表記で、ゲームでは割り当て中のキー（Q）が出ます。
