HUD レイアウトでの表示 / 非表示

HUD レイアウトから、ゲームのパーツ（ボスバー・スコアボード・チャット・ペーパードール）と Lamium の要素（情報 HUD・ミニマップ・耐久値など）の表示を切り替える案です。論点は二つ: 「状況によって今は出ていないだけ」の要素（白い点線）と「自分で隠した」要素をどう見分けるか、そして Lamium の要素はツールバーがすでに長いので、切り替えをどこに置くか。要素をクリックすると選択、何もない所をクリックすると選択解除です。

HUD レイアウト

決定事項（2026-11-14、推奨どおり）

  1. エディタで切り替える「表示」は、今ある機能のスイッチそのもの。 推奨。情報 HUD やミニマップは、設定画面の機能スイッチと同じ値を切り替えます（新しい設定は増やしません）。ゲームのパーツには新しく「表示」の値を足します。
  2. 隠した要素の見せ方。 推奨: A。本来の大きさで薄く描き、黄色の斜線とタグの「・非表示」を付けます。白い点線（今は出ていないだけ）と形が違い、場所も見えるので隠したまま動かせます。B は点線どうしで色だけの違いになり、C は選ぶまで場所が分かりません。
  3. 切り替えの場所。 推奨: T2。名前タグの先頭にチェックを置き、選択中・ポインタを乗せた要素のタグに出ます。ツールバーの長さは変わらず、全要素で同じ操作です。T1 は Lamium の要素だとボタンが 6 個になり狭い画面で折り返しが要ります。T3 は一覧で一度に切り替えられますが、以前「要素の一覧は今は作らない」と決めたものの見直しになります（T2 と併用も可）。
  4. ゲームのパーツの非表示はメインスイッチ（ゲーム HUD の配置変更）に従う。 推奨。オフで全部バニラに戻る約束を守れます。パーツのスイッチがオフならそのパーツは完全にバニラ（隠しもしない）とし、「表示」は扱うときだけ効く、と読みます。メインをオンにするとチャットが左下へ動く点は、チャットのパーツをオフにすれば避けられます。
  5. 今の「ボスバーを隠す」（視覚効果を隠す）はボスバーの「表示」に移す。キーはそのまま（保存される値は information.showBossBars に移り、古い設定は読み込み時に移します）。使っていた人は更新時に、メインをオン・ボスバーだけ選択・表示しない、に移すので見た目は変わりません。キーで隠すと必要ならボスバーだけでメインをオンにし、もう一度押すと表示に戻すだけです。視覚効果を隠すからは行がなくなります。
  6. チャットを隠すと HUD 上のメッセージだけが消える。チャット画面（T キー）は標準のままです。
