プレイ中のインベントリ表示と空き枠の数

インベントリの中身（上の 27 枠、設定で 36 枠）を 9×3 の枠で、空き枠の数を別の小さな要素で出します。どちらも HUD レイアウト編集で動かせ、大きさは 75〜150 %。アイテムの絵は仮のもので、実物はホットバーと同じゲームのアイコン（Lamium の ItemIcon）です。

決定事項（2026-10-10）

  • 並べる枠は上の 27 枠が既定。設定でホットバーを足した 36 枠（ホットバーは下に区切り線を挟んで 1 段）。防具とオフハンドは入れない（装備は別の表示がある）。
  • 並び順はバニラのインベントリ画面と同じ 9×3。空いた枠は薄い枠だけ描く。
  • アイテムはホットバーと同じ絵に個数と耐久値のバー（盾の光沢はまだ出ない、L-91）。
  • 大きさはホットバーと同じ 1 枠 18 を 100 % として、HUD レイアウト編集で 75〜150 %。
  • 空き枠の数は別の要素「空き 24」（総数は出さない）。空きが 0 なら注意色（警告の黄）。
  • オンの間は常に表示し、何かの画面（インベントリ、チャット、メニュー）を開いている間は隠す。表示を切り替えるホットキーを用意（既定は割り当てなし）。
  • どちらも初期状態はオフ。背景はほかの HUD と同じ カード / 行ごと / なし。
  • 既定の位置は右の中央、空き枠の数はそのすぐ上（右下は画面の幅によってホットバーと重なる）。
  • 空き枠の数だけを出す使い方もできる（インベントリの表示はオフのまま）。「ホットバーも含める」は両方に共通の設定。
