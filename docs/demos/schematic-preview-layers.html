プレビューで「ここまでの層」を見る：操作をどこに置くか

3 つの案を並べています。どれもプレビューはドラッグで回転、ホイールで拡大・縮小できます。層は高さ（下から）だけでなく東西・南北にも切れます。ブロックは仮の色です。

確認したいこと
  1. A 配置の層と同じ：プレビューの層の操作は、配置タブの「層の向き・表示・層」をそのまま変えます。プレビューとワールドのゴーストがいつも同じになります。照合タブ向き。ファイルタブ（まだ配置していない）では使えません。
  2. B プレビュー専用：プレビューの端の縦スライダーと向きの切り替えで、プレビューだけを切ります。ワールドには影響しません。ファイルタブでも使えます。
  3. C プレビュー専用＋ワールドへ反映：B と同じ操作に「ワールドにも」ボタンを足し、気に入った切り方を配置に移せます。
  4. スライダーの位置（プレビューの右端の縦、下端の横）と、軸の切り替え（ボタン 3 つ、または回している向きから自動で選ぶ）はどうか。
