ハイライトするブロックの一覧と、まだ見ていないブロックの追加

今はキーで「照準のブロックを追加 / 外す」しかなく、何を指定したか見えないこと、まだ見つけていないブロックを指定できないことが問題です。ここでは一覧画面を 1 つ足し、左に指定中の種類、右に追加の手段を置きます。追加の手段は A 名前で検索してリスト と B アイコンの格子 の 2 案です。タブで場面を切り替えられ、検索・追加・削除は実際に操作できます（プレイ中の場面では H キーで照準のダイヤモンド鉱石を追加 / 外せます）。ブロックの絵は仮のものです。

設定画面の行（「カメラ」の中、今の「ブロックのハイライト」の子）

カメラと見た目
▾ ブロックのハイライト 試験的未割り当て
ハイライトするブロック 5 種類一覧を開く

照準のブロックを追加 / 外すキーは今のまま残します（一覧を開かなくても使える）。一覧専用のキーは作らず、設定の行から開きます。

左：指定中の種類

  • アイコン・表示名・ID。並びは追加した順（新しいものが下）
  • × は 2 回押しで外す（形状やウェイポイントと同じ）
  • 「近くに N」：今描いているハイライト面の記録から数えるので、走査も追加の負荷もなし。描画距離の中で、壁の向こうは数えない（見えていない面は記録されない）。0 なら「なし」
  • 色の選択はなし（全種類が同じ虹色、2026-11-08 決定）

A 検索リスト

  • 入力欄に打つと、表示名（今の言語）と ID の両方で絞り込む
  • 何も打っていないときは「よく使う」候補（鉱石・古代の残骸・スポナーなど）を出す
  • 行をクリックで追加、もう一度で外す。見たことのないブロックも全部出る
  • チェストなどブロックエンティティは灰色で「対象外」

B アイコン格子

  • 分類チップ（鉱石 / 貴重 / 自然 / すべて）と検索欄で絞り、アイコンを並べる
  • 指定中は緑の枠と右上の印。クリックで追加 / 外す
  • 名前はアイコンに乗せたときだけ下の帯に出る。似た絵（各種の石）は見分けにくい
  • アイコンのないブロック（光源ブロックなど）は描けないので、結局リストが要る

プレイ中の補助

  • キーで追加 / 外したときのトーストにブロック名とアイコン
  • 照準先の情報カードに「ハイライト中」の 1 行
  • どちらも小さく、A / B のどちらを選んでも入れられる

決めてほしいこと

  1. 追加の手段：A 検索リスト か B アイコン格子 か。おすすめは A（名前と ID が常に見え、アイコンのないブロックも扱え、実装も軽い）。
  2. 表示名で検索できるようにするか。ID だけなら確実で簡単。表示名にはゲームの翻訳を引く必要があり、実装時に SDK で可否を確かめる。おすすめは両方（表示名が引けなければ ID だけで出す）。
  3. 「近くに N」列を出すか。指定が効いているか・近くにあるかがひと目で分かる。数字が描画距離と見えている面に限られることは脚注で示す。
  4. 仲間のまとめ追加。ダイヤモンド鉱石を追加すると「深層岩のダイヤモンド鉱石も追加」の案内を 1 行出すか。ID の deepslate_ 付きを探すだけの単純な規則にする。
  5. トーストと情報カードの 1 行を入れるか。
