形状の画面：下書きから作成し、右寄せは画面内で切り替える

A 案を土台にしました。ヘッダーの「右に寄せる」で B の配置に切り替えられます（最後の状態を覚えます）。追加ボタンはすぐに形状を作らず、下書きを開きます。下書きはワールドに水色の破線で仮表示され、「作成」で確定します。描き方は形状ごとに選べ、既定は「面」です。値を変えてもスクロール位置は保たれます。

設定画面側に置く「形状の描画」

機能一覧からは形状の画面を開かず、表示の ON/OFF と2つのキーだけを置きます（情報・オーバーレイ内）。

情報・オーバーレイ
▾ 形状の描画 2未割り当て
表示の切り替え未割り当て
形状の画面を開く未割り当て

親の行のスイッチは全形状の表示の ON/OFF。キー欄は「表示の切り替え」を主キーとして表示します。

新しい形状の流れ

  • 「新しい形状」で種類を選ぶと下書きが開く（一覧に「下書き」として表示）
  • 中心の基準：立っているブロックの中心 / 今いる正確な位置 / 見ているブロック
  • 下書きはワールドに破線で仮表示。「作成」で確定、「取消」で破棄
  • 「ここへ移動」も同じ基準で中心を合わせ直す

右に寄せる（B）の扱い

  • 設定項目にはせず、形状の画面のヘッダーのボタンで切り替え
  • 位置合わせは右寄せ、一覧の整理は大きく、と使い分ける
  • 部品は同じで位置と幅が変わるだけなので、保守の負担は小さい

描き方

  • 形状ごとに 面 / 線 / 線＋面。新しい形状の既定は面
  • 線は、大きな形状を透かして見る・負荷を下げるときに使う
  • 描画処理は編集時だけ作り直し、毎フレームの再生成をやめる

確認したいこと

  1. 下書き → 作成の流れと、中心の基準の3択でよいか（既定は「立っているブロックの中心」）
  2. 右寄せをヘッダーのボタンで切り替える形でよいか
  3. 設定画面側の「形状の描画」の構成でよいか
