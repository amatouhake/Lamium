確認したいこと
  1. 右側の並べ方：A はプレビューの大きさが変わらず、文字が増えると下でスクロールします。B はプレビューが大きく、選んだ行の詳細をプレビューの下側に重ねます。どちらがよいか。
  2. 間違いの見せ方：1 は今の色混ぜ。2 は正しいブロックを薄くして間違いだけを濃く残します（大きい建物で探しやすい）。3 は間違いに色の枠と上に伸びる目印を付けます（遠くからでも見える）。組み合わせも可能です（例: 2 + 3）。
  3. 選んだ間違い：「寄る」はその場所を中心に拡大します（描く順は向きだけで決まるので、拡大・移動しても崩れません）。「その層で切る」はその高さより上を隠して、建物の中の間違いも見えるようにします。両方を併用することもできます。
  4. ホイールでの拡大・縮小：ファイルタブのプレビューにも同じ操作を入れる想定です。拡大したときの移動（右ドラッグなど）も要るか。
  5. 種類の表示：リスト上の絞り込み（違う・余計 / 状態違い / 未設置）とプレビューの表示を連動させるか、プレビューはいつも全種類を出すか。
