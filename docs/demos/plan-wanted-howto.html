欲しい物の行と「作り方」のモック

L-370。前回までに決まったこと: 欲しい物は表の形（数字を列にそろえる）、操作は右の決まった列、選択は全体に効く「作り方」の一覧で選ぶ、内訳は読むだけ。ここで比べるのは 1 点ずつです。アイテムの絵は色の四角で代用。押して試せます。

1. 欲しい物の操作: いつも見せるか、ポインタを当てた行だけか

表の形は同じ。列は［開閉］［絵］［名前］［所持］［欲しい］［素材の帯］［操作］。名前の列は 220 単位の窓ではかなり狭く、長い名前は切れてポインタで全部出る。手で入れた物は「欲しい」の欄が数の調整（- N +）になり、設計図の物は数字だけ（数は設計図が決める）で、右端に小さく「図」。違うのは操作を見せるタイミングだけ。

a: いつも見せる手で入れた物の行には、いつも「- N +」と「×（外す）」が出ている。

b: ポインタを当てた行だけふだんは「欲しい」の欄に数字だけ。ポインタを当てた手で入れた物の行だけ、同じ欄が「- N +」に替わり、右に「×」が出る。何も動かない。

2. 作り方のタブと、読むだけの内訳

内訳の工程には「作り方」の状態（自動 / 選んだ物の名前）だけが出て、押すと作り方のタブの該当する行へ移る。作り方のタブでは、行を押すと候補がマスで開き、一番上が「自動」または「どれでも」。一覧に出す範囲は上の切り替えで比べられる。
