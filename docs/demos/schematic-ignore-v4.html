このモックで入れたこと

  • フィルター：すべて／ブロック違い／状態違い／未設置 から1つ。数は付けません。余計なブロック（空気 → 丸石）はブロック違いに入ります。
  • 無視は種類ではなく別のオン・オフ：無視した行も元の種類のまま、元の場所に出ます。どのフィルターでも出ます。
  • 選んだ行：見出し「違う項目（レバー）」の下に項目ごとの違い。ボタンは「全レバーで無視」、無視中は「全レバーで無視中」と「戻す」。看板の文字や音符ブロックの音程も同じ形です。下の操作行に「この場所を無視」／「この場所の無視をやめる」。
  • 複数行：ワールドで示す／選んだ場所を無視／選んだ場所の無視をやめる だけ。
  • 無視の設定：操作行の右端にいつも出ます。押すと照合タブが切り替わり、もう一度押すか Esc で戻ります。左は「無視している場所」と「設計図のブロック」、右は選んだものの詳細。

このモックで決めたいこと

  1. 無視した行の見え方：上の A〜D。A が推奨です（文字は普段どおり読めて、四角の形と札で見分けます）。
  2. 札の言葉：A「場所を無視」「違いを無視」（推奨。なぜ無視しているかが一覧で分かる）か、B「無視中」だけか。
  3. 一部の項目だけ無視している行（例：レバーの「動力」は無視、「向き」は違う）：まだ数える間違いなので札は出さない（推奨）。右の欄で項目ごとに分かります。
  4. 場所を無視した行の右の欄：違う項目はそのまま出し、ボタンは隠して「この場所は無視中で、数えません」と出す（推奨）。
  5. 無視の設定の「設計図のブロック」に、比べる項目がないブロック（石など）を並べるか：並べない（推奨。押しても何もできない行を作らない）。
