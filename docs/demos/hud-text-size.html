HUD 要素の大きさと文字の大きさ

いまは HUD レイアウトエディタの倍率ひとつが、要素の図形と文字をまとめて大きくします（地図だけは「地図の文字の大きさ」を掛け算）。下の画面で候補を切り替え、要素をクリックして選び、右の値を動かして比べてください。画面は 480×270 GUI 単位を幅に合わせて描いています。

モデル

候補の違い

確認したいこと（どの候補でも決める）

  • アイコンに付く文字：スロット隅の個数、バー横の数字。文字だけ大きくするとセルからはみ出す（インベントリで文字を 200% にして確かめられます）。はみ出しを許すか、セルの大きさで頭打ちにするか。
  • 今の見た目の引き継ぎ：保存済みのレイアウトは、どの候補でも今と同じ見た目になるよう一度だけ換算する。map.textSize は新しい「文字」に吸収する。
  • ゲーム本来の HUD 部品（ホットバー、体力など）は今どおり位置と倍率だけ。
