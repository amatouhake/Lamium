Ignoring check differences: the placement-wide model

The model agreed after using the v2 build (L-183 "Next"). There are two kinds only. Do not count this cell leaves one cell out. Ignore a difference in this placement is a rule "<block>: <item>" that applies to every such block of the placement. Block states and block entity fields are presented alike. As in v2, the game screen is Japanese and the English names follow in the notes. Strings tagged new do not exist yet. Block art, icons and positions are placeholders. Click a row. Ctrl+click adds rows, Shift+click takes a range, Ctrl+A selects all and Esc clears or goes back (click the screen first). The click-mode buttons do the same on touch.

1. The Check list: one list with filter toggles

  • The four kind tabs become filter toggles in one row: 間違い Mistakes, 状態違い Wrong state, 未設置 Not placed, and 無視中new Ignored. All are on except Ignored. Each switches on its own. Turning all off empties the list (ここに表示するものはありません。).
  • With Mistakes beside a separate Wrong state, Mistakes means wrong or extra blocks (the red group). Today "Mistakes" means red plus yellow. See question 1.
  • Counts sit after each label, as v2 and today's tabs show them. The Ignored count is the number of ignored rows: cells not counted, plus rows whose every difference is ignored.
  • An ignored row is shown only while Ignored is on, whatever its kind. It sits in its usual place (mistakes before not placed, nearest first), dimmed, with a tag: 数えない or 違いを無視new. A row with only some differences ignored is still a yellow mistake and is not tagged.

2. A wrong-state row: the detail pane

  • Under 違い each differing item is one line, "item now → should be". It does not matter whether the item is a block state (a lever's 動力, a repeater's 遅延) or a block entity field (a sign's 文字, a note block's 音程): the lines look and work the same.
  • Each line has この違いを無視new Ignore this difference. It adds the rule レバー: 動力 for the whole placement. Every lever row's 動力 line dims at once, and rows left with nothing to fix count as correct. 正しい rises and the total stays the same. A note under the lines says which blocks the rule reaches.
  • An ignored line is dimmed and tagged 無視中 · 配置全体new. Its 戻す removes the rule, so every lever is compared again.
  • この場所を数えない: オフ / オンnew Do not count this cell is a switch in the action row. On, the cell leaves every count and the materials, and the total drops by one. It works for every row kind except extra blocks (air in the file), which keep extras' own 数えない.

4. Several rows selected

  • The pane has a count header (N 行を選択) and the names in list order up to what fits, then ほか N 件.
  • Actions: ワールドで示す, 数えないnew Do not count and 数え直すnew Count again. A button that would change nothing is disabled, and extra-block rows are skipped.
  • There is no difference ignoring for several rows. A faint line points to the single row and to 無視の設定 (question 6).

3. Ignore settings

  • 無視の設定new Ignore settings is always at the right of the action row, with no count and no colon. It opens a view over the list and the detail columns. The sidebar stays. Esc or 照合に戻るnew returns to the list as it was.
  • Left column, two headings. 数えない場所new Cells not counted lists icon, block name, position and 戻す, nearest first. 無視している違い Ignored differences lists icon, block name, item and 戻す, in materials order. Each heading shows its count, and the footer shows the entries used out of 64. Two-press すべて戻す sits in the action row.
  • Stale entries are dimmed and listed last under their own heading. They are not applied but can be removed. A cell whose block left the file, or a rule whose block is no longer in the file, is tagged 設計図にない. A one-cell state entry saved by the v2 build is not widened to a rule. It shows here, stale, tagged 以前の形式new with its position (question 4).
  • Right column, 設計図のブロックnew: rules can be made before anything differs. The file's blocks are listed in materials order with their counts. Each opens to its compared items, and each item has a switch 無視: オフ / オン. A switch and a 戻す on the left are the same rule, so turning one changes the other. An item that differs somewhere right now shows N か所で違うnew. A block with no compared items (stone) reads 比べる項目はありませんnew. The chest lists only 向き because contents are never compared.
  • Unchanged: the every-placement switches (redstone signal, plant growth, block entities, sign text) stay in the Check settings. The key and the radial-menu item toggle "do not count" for the looked-at cell. Extras keep their per-placement 数えない.
確認したいこと (choices L-183 does not settle; the mockup takes the first answer)
  1. "Mistakes" filter: with Wrong state beside it, the mockup makes it wrong or extra blocks only. Keep the word 間違い Mistakes, or rename it to today's chip text 違う・余計 Wrong or extra, which says what it now filters?
  2. Ignored rows and the kind toggles: the mockup shows an ignored row whenever Ignored is on, even if its kind is off. The other choice: Ignored on and its kind on. That reads as "also show ignored", but the Ignored count then depends on the other toggles.
  3. Filter persistence: should the toggles be remembered across screens and sessions (like a setting), or reset to "all but Ignored" each time the screen opens? Not shown.
  4. Old one-cell state entries: they are shown stale with 以前の形式 and a position, under 無視している違い. 設計図にない would be wrong for them. Is the wording fine? Should the list offer to turn one into the matching placement-wide rule? Not offered here.
  5. The ignore view's layout: it takes the list and detail columns, and each column scrolls on its own (the game has no scrolling in this pane yet, so long lists would need a scroll bar or ほか N 件 paging). Or should it be a separate screen? The footer shows the use of the cap as 5 / 64. Keep that?
  6. Several rows: show the faint line 違いの無視は 1 行ずつ、または「無視の設定」で行います。new, or nothing?
  7. Item switch wording in 設計図のブロック: 無視: オフ / オン after the item name. The mockup also shows N か所で違う beside items that differ now. Keep both?
  8. Key, radial menu and toast wording: the action now means "do not count". Rename 見ているブロックを無視 / ブロックごと無視: … to 見ているブロックを数えない / 数えない: … (and the target card's 設計図: ブロックごと無視)? Not drawn.
  9. Detail tag wording: the ignored line's tag reads 無視中 · 配置全体, and the note names the block (この配置のレバーすべてに効きます). Name the rule in the tag instead (無視中: レバー: 動力)?
