資材タブで「元の素材」まで見る

今の資材タブ（UI Profile 75%、1920×1080 と同じ割合）に、右側のスイッチを 1 つ足す案です。オンにすると一覧が「集めるもの」と「作るもの」に変わります。画面の中のスイッチと行はクリックできます。数字はこのページの中で、ゲームと同じ計算（手持ちを先に使う、まとめてから切り上げる）をしています。アイコンの色は仮のものです。

この案の決めごと

  • スイッチは保存しない。「表示中の層だけ」と同じで、画面を開き直すとオフに戻ります。
  • 集めるものは、手持ち（シュルカーボックスの中も含む）を先に使った後の数です。完成品を持っていればその分は作りません。
  • 作るものは、作業場所と回数、できる数、余りを出します。かまどの燃料は数えません。
  • 「どれでも」の素材（板材、石炭と木炭、精錬できる鉱石）は 1 行にまとめ、手持ちは種類を合計します。その先（板材 → 原木）へは、種類を選べるようになるまでたどりません。
  • 採掘で手に入るもの（ダイヤ、レッドストーンなど）は集める側に出します。
  • エンティティと、アイテムの無い行は計画に入れません。
  • 読み込み中は一覧に一言、一時停止中はスイッチを薄くして理由を出します。

見てほしい所

  1. 集めるものの列。「あと」だけにするか、「必要・手持ち・あと」の 3 列にするか（上の切り替え）。
  2. 作るものの並び。先に作る物から（丸石を焼く → 石レンガ）か、完成品から（石レンガ ← 石）か。
  3. 右側の詳細。集めるものは換算と使い道、作るものはレシピ。これで足りるか。
  4. 手持ちから使った分は右側の 1 行（「手持ちから 7 種類」）と各行の詳細だけです。一覧に 3 つ目の区画が要るか。

最初の版に入れないもの

  • 「どれでも」の種類を選ぶ操作、「ここで止める」の印、レシピの切り替え、保存。
  • ベッドの色（今は最初の色で計算されます）。
