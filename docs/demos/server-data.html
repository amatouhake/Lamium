保存データを見る・選び直す

サーバーのアドレスやポートが変わると、Lamium は同じサーバーだと分からず、ウェイポイント・設計図の配置・地図・死亡時の配置が「消えた」ように見えます。第 3 版は、案内を出す各画面を実際の構成に合わせて描き直し、設定の行には小さなリンクを足し、ポートの設定をスイッチにしました。サーバー名やアドレスはすべて架空のものです。

第 2 版から変えた点

  1. 設定の行に小さなリンク（画面 2）。ウェイポイント、ワールドマップ、設計図の各機能の下に「保存データ　<名前>　選び直す >」をいつも出します。
  2. 案内の条件を「空」から「候補のほうが中身が多い」に。ワールドマップは入った直後から記録されるので、空を条件にすると出ないためです。比べるのは、その画面で見るデータ（ウェイポイントの件数、配置の件数、地図の大きさ）です。
  3. 案内のボタンは「今後は表示しない」。押すと、このサーバーではその案内を出しません。保存データの画面からは、いつでも選び直せます。
  4. ツール画面を実際の構成で描き直し（画面 4〜6）。ウェイポイントと設計図は一覧の上、列見出しの手前に置きます。ワールドマップは全画面の独自の画面なので、上部バーの下の左上に重ねて出し、地図の操作は妨げません。
  5. ポートの設定はスイッチ。チェックボックスは使いません（DESIGN の規則）。サーバーのデータなら使用中でなくても詳細に出るので、あとから一覧で選んでオフにできます。「このデータを使う」の上に置きました。
  6. 「消す」は 2 回押し。2 回目のボタンに、消える中身（ウェイポイントの件数、地図の大きさ）を書きます。使用中のデータは消せません。

そのまま進める点

  • 入口は「全般」の「保存データ」。見出しではなくタグで区別し、サイドバーは残す。選ぶとその場で切り替わる。
  • ローカルワールドとフレンドのワールドも一覧に出す。サーバーには使えないので「このデータを使う」は出さない。
  • 地図の縮小表示は、そのデータで最後にいた場所を中心に、オーバーワールドの地表。
  • ポートを問わない設定がオンのとき、同じアドレスの別ポートで別のデータを選ぶと、そのポートだけ例外として覚える。
