保存データを見る・選び直す

サーバーのアドレスやポートが変わると、Lamium は同じサーバーだと分からず、ウェイポイント・設計図の配置・地図・死亡時の配置が「消えた」ように見えます。第 2 版では、入口を「全般」に置き、ローカルワールドやフレンドのワールドも含めて保存データを一覧し、中身を見て選び直せるようにしました。サーバー名やアドレスはすべて架空のものです。

案内は、その画面で見るデータが空で、同じサーバーかもしれないデータにそれがあるときだけ出ます。「違うサーバー」を押すと、このサーバーでは二度と出ません。

第 1 版から変えた点

  1. 入口は「全般」の「保存データ」。ワールドマップの下には置きません。影響する画面（ウェイポイント、設計図、ワールドマップ）には、空のときだけ案内を出します。
  2. 見出しで分けず、タグで区別します。緑「使用中」、黄「候補」、灰色の枠は種類（ローカル、フレンド、サーバー）。並びは、使用中、候補、あとは最後に使った順です。
  3. 左のサイドバーは残します。「全般」の中の 1 ページとして開きます。
  4. 選ぶとその場で切り替わります。入り直しは要りません。
  5. ローカルワールドとフレンドのワールドも一覧に出します。大きさを確かめられます。これらは選び直しの対象にはならないので、「このデータを使う」は出ません。
  6. 「このアドレスなら、ポートが違ってもこのデータを使う」を、使用中のサーバーのデータに付けました。Realms のように毎回ポートが変わる場合のためです。既定はオフです。
  7. 詳細にプレビュー。地図の縮小表示（ウェイポイントの位置つき）と、ウェイポイントの名前を数件。どのサーバーのデータかを見て判断できます。

決めてほしいこと

  • 「消す」を付けるか。大きさを確かめる目的なら、不要なデータを消したくなるはずです。付ける場合は 2 回押しの確認にし、使用中のデータは消せないようにします。モックでは付けてあります。
  • 地図の縮小表示は、どの範囲を出すか。案: そのデータで最後にいた場所を中心に、オーバーワールドの地表。地図がないデータは「地図なし」と出します。
  • 「ポートが違ってもこのデータを使う」をオンにしたあと、同じアドレスの別ポートに本当に別のサーバーがあった場合。案: そのサーバーに入ったときに保存データの画面で別のデータを選べば、そのポートだけ例外として覚えます。
  • 案内を出す画面は、ウェイポイント・設計図・ワールドマップの 3 つでよいか。
