サーバーのデータを選び直す

サーバーのアドレスやポートが変わると、Lamium は同じサーバーだと分からず、ウェイポイント・設計図の配置・地図・死亡時の配置が「消えた」ように見えます。データは古い名前の下に残っているので、プレイヤーが「このサーバーはあのデータを使う」と選べる入口を作ります。何も消さず、いつでも戻せることを前提にしています。

このサーバーにはまだデータがありません。
play.example.net:19133 のデータ（ウェイポイント 12、配置 3、地図 3.4 MB、最後に使用 11-02）が、同じサーバーのものかもしれません。
このデータを使うほかのデータを見る違うサーバー
ウェイポイントはまだありません。
案内は、いまのデータが空で、同じサーバーかもしれないデータがあるときだけ出ます。「違うサーバー」を押すと、このサーバーでは二度と出ません。

提案

  1. 入口は設定の「ワールドマップ」の下の行。すでにある「保存した地図（このワールド）」の隣です。地図だけの話ではありませんが、「消えた」と気づくのは地図とウェイポイントなので、ここが一番見つけやすいと考えました。
  2. 選ぶ画面は一覧と詳細。「いま使っているデータ」を一番上に、次に「このサーバーかもしれないデータ」、最後に「ほかのサーバーのデータ」を並べます。
  3. 「かもしれない」の基準は、(a) 同じサーバーだと判定したのに使わなかった名前、(b) ワールド ID が同じ、(c) ホスト名か IP が同じでポートだけ違う、のどれか。ポート違いは別サーバーのこともあるので、自動では使わず候補に出すだけです。
  4. 選ぶと、その場で切り替わります。いままで使っていたデータは消えず、一覧に残ります。もう一度選べば戻せます。
  5. B: 空のときの案内も出します。ウェイポイント画面とワールドマップで、いまのデータが空で候補があるときだけ。入口を知らなくても気づけます。

決めてほしいこと

  • 入口の場所は「ワールドマップ」の下でよいか（ほかの案: ウェイポイントの下、「全般」）。
  • 案内（B）を出すか。出す場合、ウェイポイント画面とワールドマップの両方でよいか。
  • 切り替えはその場で反映するか、入り直してからにするか（その場のほうが分かりやすいが、地図の読み直しが入る）。
  • 名前の見せ方。フォルダ名そのまま（http___198.51.100.20_19133_19133）ではなく、198.51.100.20:19133 の形に直して見せる想定です。
  • ローカルワールドとフレンドのワールドのデータは一覧に出さない想定です（アドレスがなく、取り違えの原因にならないため）。
