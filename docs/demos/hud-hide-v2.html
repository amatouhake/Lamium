HUD レイアウト: 状況で出る要素と隠した要素

二回目の案（2版）です。名前に「・非表示」を足すのはやめ、状態は模様と切り替えで表します。切り替えは選択中の要素にだけ出て、名前タグの位置は動きません。要素をクリックすると選択、何もない所をクリックすると選択解除です。ポインタを乗せると枠が明るくなり、名前が出ます（ボタンは出ません）。

確認したいこと（推奨つき）

  1. 状況で出る要素の見せ方。A（いま表示中）: 状況で出る要素は中身を 50% で出し、白い点線と名前を付けます。隠した要素は中身なしの灰色の斜線と名前です。置いたものが全部見えるぶん見本が多く並ぶので、画面の混み具合を見てください。B は上のボタンで比べられます。
  2. 名前タグ。名前だけを表示し、「・非表示」は付けません。状況で出る要素と隠した要素は、いつも名前を出します。重なりを避ける処理は残し、空きがないときも別のタグに重ねず、要素の枠の内側の上端に置きます。
  3. 切り替えの形。選択中の要素の名前タグに、設定画面や切り替え通知と同じスイッチをつなげます。位置は基準と反対側の端（左寄せのタグなら右、右寄せなら左）なので、名前は動きません。ポインタを乗せただけでは出ず、ツールバーは今のままです。
  4. 凡例。何も選んでいないときのパネルに「点線 = 状況で表示」「斜線 = 非表示」を出します。
