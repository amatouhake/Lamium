ホットキーの重なりの警告とツールチップ

キーの重なりを、ホットキー一覧でも機能ごとの設定画面でも、同じ見た目で知らせます。詳しい内容は、キー欄にマウスを乗せると出るツールチップにまとめます。上の切り替えで各案を比べてください。行はクリックか ↑↓ で選べます（キーボード操作の再現）。割り当ては 2026-09-25 のスクリーンショットをもとに、重複の例を1つ足したものです。

A. 警告の出し方

  • 今の形：「重なり」「重複」の文字の印。意味は分かりやすいが、幅が足りないと入らない。キーが長いとホットキー一覧でも消える（スクリーンショットの Ctrl + J がこれ）
  • キーを黄色に：Tweakeroo と同じ考え方。幅に関係なくいつも出せて、どの画面でも同じ見た目になる
  • 黄色＋件数：黄色のキーの後ろに「3」のような件数を足す。入らないときは件数だけ省く
  • 左に黄色い線：キーの見た目は変えない。いちばん控えめだが、見落としやすい

ツールチップの中身

  • 関係の種類ごとに見出しを付け、組み合わせと操作名を1行ずつ並べる
  • 種類：同じキー（同時に動作） / このキーで始まる組み合わせ（このキーは離したときに動作） / このキーを含む長い組み合わせ（そちらが優先） / このキーに含まれる短い組み合わせ（このキーが優先） / 順番違い
  • 「離したときに動作」は種類の見出しではなく、先頭に黄色い1行で出す
  • 入りきらない分は「ほか N 件」

説明欄

  • 説明欄は、機能・操作の説明と「押す／押している間／切り替え」に戻す
  • E で「説明欄に1行だけ」を選んだ場合は、重なりがある行を選んだときだけ黄色い1行を足す
  • 機能の行（例：デバッグ表示）でも、そのキー欄に乗せれば同じツールチップが出る

決定事項（2026-09-25）

  1. A：キーを黄色にする（文字の印はキーと紛らわしいので付けない）。B：重複は塗り、重なりは枠。C：キー欄に乗せたとき。D：キー欄の下に固定（下に入らなければ上）。
  2. E：キーボードで行を選んだときもツールチップを出す。説明欄には出さない（キーボードで操作している人にマウスを使わせない）。

検討時の質問

  1. A. 警告の出し方：私の案は「キーを黄色に」です。どの幅でも出せて、見た目がそろいます。
  2. B. 区別：同じキー（全部同時に動く）と重なり（長い方が優先）を見た目で分けるか。私の案は「重複は塗り、重なりは枠」です。重複はわざとまとめて切り替えるための使い方もあるので、別物として見分けられる方がよいと考えます。
  3. C / D. ツールチップ：私の案は「キー欄に乗せたとき」と「キー欄の下に固定」です。行全体にすると、行をクリックするたびにツールチップが出て邪魔になりやすいためです。
  4. E. キーボード：私の案は「説明欄に1行だけ」です。
  5. ツールチップの文言と、種類の分け方は分かりやすいか。
