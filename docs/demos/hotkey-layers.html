ホットキー画面で「どこで効くか」と固定の操作を見せる

各操作が効く場所（プレイ中・アイテム画面・アイテム画面上の窓・ワールド外）はもう内部で決まっていて、衝突の吹き出しにも出ている。ホットキー画面の行でそれをどう見せるかと、割り当てられない固定の操作（レシピの一覧のクリック、インベントリ転送の操作）をどう並べるかを比べる。行を押すと選択が移り、下の説明欄が変わる。

固定の操作
窓の呼び方
ウィンドウ

ピンクの字 = モックアップ上の省略（実際の画面には出ない）。画面は一覧が入るように縦に伸ばしている。

確認したいこと

  • 場所の出し方を A / B / C のどれにするか。A はプレイ中だけで効く操作（大半）には何も付けない。
  • 固定の操作を読み取り専用の行で出すか、そのときスイッチも付けるか。スイッチはインベントリ転送の操作には今もある（設定画面の子の行）が、レシピの一覧のクリックにはまだない。付けるなら新しい設定になる。
  • 固定のキーの見た目（枠だけで中を塗らず、文字を淡く）。編集できないことが分かるか。
  • 窓の呼び方。衝突の吹き出しは今「アイテム画面上の窓」。
  • 作りながら決めた次の2点もここで確認したい：条件（フリーカメラ中、レシピや計画がオン）では割り当てを衝突から外さないこと。吹き出しで重なる場所を相手の名前の後ろに淡く出すこと。
