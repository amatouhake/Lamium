HUD レイアウト編集の作り直し：編集のしかた、カードの見た目、ターゲットカード

前回の実装を触って出た違和感をもとに作り直した比較用のデモです。要素はドラッグで動かせます。上のボタンで編集のしかた（A / B / C）とカードの見た目を切り替え、触り比べてください。「固定」はなくし、置いた場所から伸びる向きを自動で決めます。画面の端にもぴったり置けます。

このデモで変えたこと

  • 「基準点を固定」をなくした。置いた場所が画面のどの 3 分の 1 にあるかで、伸びる向きを自動で決める（左下に置いた情報表示は上に伸びる）
  • 3×3 のマスは「その位置に寄せる」ボタン。いま基準になっているマスが光る
  • 画面の端・中央の線に近づけると吸い付く（黄色い線）。端にもぴったり置ける
  • 矢印キーで 1、Shift＋矢印で 10 動かせる（要素を選んでから）
  • ターゲットカードにアイコン、成長のバー、体力のハート、道具の適正を追加

確認したいこと

  1. 編集のしかたは A・B・C のどれがよいか（混ぜてもよい）
  2. カードの見た目は A・B・C のどれがよいか
  3. ターゲットカードの中身（アイコン、ハート、バー、適正ツール）の方向は合っているか
  4. 「固定」をなくし、寄せるマスと吸い付きで置く方式で困る場面はないか
