A 案（サイドバー＋表）を土台に、下の切り替えで比べられるようにしました。描画は引き続き、Lamium がゲーム内で描ける「文字」と「半透明の矩形」だけです。キー欄から「長押し / 切替 / 押す」の表示を外し、キーの行を選んだときに下の説明欄で伝えるようにしました。フリールックには「起動方法」の設定を足しています。

ON/OFF の3案

  • スイッチ：Bedrock 標準の設定画面と同じ形。言語に依存せず、つまみの位置でも ON/OFF が分かる
  • 文字：ON / OFF の文字入り。いちばん明確だが幅を取る
  • チェック：最も省スペース。ゲームの設定画面というより PC アプリ寄りの印象

ウィンドウサイズへの対応

  • 16:9 の通常表示はこれまでのデモと同じ
  • パネルは画面に合わせて縮み、幅が足りないとキー列を細くする
  • さらに狭いとサイドバーを上部のタブに切り替える
  • 高さが低いと説明欄を1行にし、操作のヒントを隠す

多言語対応

  • 英語が標準で、ゲームの言語が日本語なら日本語（今の Mod と同じ仕組み）
  • 英語の方が項目名が長いので、列からはみ出す部分は「…」で省略し、全文は下の説明欄に出す
  • 中国語などは要望があれば追加（翻訳表に1列足すだけの構造）

決めてほしいこと

  1. ON/OFF の表示：スイッチ / 文字 / チェックのどれにするか
  2. 幅が狭いとき・高さが低いときの崩れ方はこれでよいか
  3. 英語表示で、読みにくい・省略が気になる項目はないか
