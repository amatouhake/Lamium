キーを押している間のプレイヤー一覧

サーバーがクライアントに送るプレイヤー一覧（描画距離の外の人も含む）を、キーを押している間だけ画面上部に出します。顔はスキンから切り抜く想定で、このモックの顔は仮に描いたものです。追加の列（機種・距離・ディメンション）は、それぞれ設定で出し入れできる案です。

きまり（案）

  • キーは既定で Tab、押している間だけ表示（キー設定で変更可）。チャットや画面を開いている間は出さない。
  • 1 行は顔＋名前。自分は先頭で緑、ホストには ★。並びは自分のあと名前順（大文字小文字は区別しない）。
  • 見出しは人数。1 列 20 人まで、超えたら列を足す。画面に入らない分は「ほか N 人」。スクロールはしない。
  • 位置は画面上部の中央。HUD レイアウト編集で動かせる要素にする。背景は他の HUD 要素と同じく カード / 行ごと / なし から選べる。
  • 一人プレイでも自分 1 人を表示。

追加の列（オプション）で出せるもの・出せないもの

  • 機種：サーバーが一覧と一緒に送る（Windows、Android、iOS、Switch、PlayStation、Xbox など）。全員分わかる。
  • 距離：その人がエンティティとして近くにいるときと、ロケーターバーの位置情報があるときだけわかる。わからない人は「—」。サーバーがロケーターバーを無効にしていると近くの人しか出ない。
  • ディメンション：近くにいる人は自分と同じ。遠くの人はロケーターバーの情報が別ディメンションを示すときだけ分かる見込み（要調査）。わからないときは「—」。
  • Ping：Bedrock のサーバーはプレイヤーごとの通信遅延を送らないため表示できない（自分の Ping は Info HUD にある）。モックでは押せない状態にしている。

保存するスイッチがない「押している間だけ」の機能なので、親の行はキーだけ（ズームと同じ形）。見た目（位置・背景）は HUD レイアウト編集で変える。

決めてほしいこと

  1. 追加の列の既定：すべてオフで始める推奨 ／ 機種だけオン。
  2. 距離の出し方：「123 m」だけ推奨 ／ 方角も付ける（「123 m 北東」）。
  3. ディメンション：列として残す（調査してから作る）推奨 ／ 今回は入れない。
  4. 背景の既定：カード推奨（Info HUD と同じ） ／ 行ごと。
