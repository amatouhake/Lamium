HUD を「要素」の集まりにして、位置と見た目を同じ方法で決める

情報表示、見ている対象の情報、状態、切り替えの通知の 4 つを HUD 要素として扱います。どの要素も「9 か所の基準点 ＋ ずらし」「大きさ」「背景」「影」を同じ操作で設定できます。上のボタンで「配置の編集」に切り替えると、要素をドラッグして動かせます。要素をクリックすると、右側に設定欄が開きます。

HUD 要素（共通の設定）

  • 位置：9 か所の基準点（四隅・各辺の中央・中央）＋ずらし
  • ドラッグすると近い基準点に吸着し、画面サイズが変わっても同じ場所に残る
  • 大きさ 75〜150%、背景（なし / 半透明）、文字の影
  • 要素：情報表示 / 見ている対象 / 状態 / 通知。将来の F3 画面も同じ仕組み

情報表示

  • 項目は一覧でオンオフと並べ替え（▲▼）。取得できない値は「取得不可」
  • 候補：座標、ブロック座標、チャンク、向き＋軸、yaw / pitch、速度、時刻と日数、天気、月齢、明るさ、バイオーム、ディメンション、FPS、Ping
  • MiniHUD と同じく、既定では少なめにオン

見ている対象・状態・通知

  • 対象はカード（アイコン・名前・ID・行・バー）と、今の文字だけの「簡易」を選べる
  • 状態は自動操作と破壊・設置制限をまとめ、色付きの印で区別
  • 通知はホットバーの上に 1.5 秒。新しい通知は前のものを置き換える

確認したいこと

  1. 配置の決め方：「配置の編集」でのドラッグと、設定画面の行の両方を用意する形でよいか。
  2. 見た目の設定は「大きさ・背景・影」で足りるか。文字色や背景の濃さも欲しいか。
  3. 見ている対象の情報は、カードを既定にし、今の文字だけの表示を「簡易」として残してよいか。
  4. 自動操作と破壊・設置制限の表示を、1 つの「状態」要素にまとめてよいか。
  5. 切り替えの通知の位置（ホットバーの上）と長さ（1.5 秒）でよいか。
  6. 情報表示の既定でオンにする項目はどれがよいか（デモでは座標・向き・バイオーム・FPS）。
