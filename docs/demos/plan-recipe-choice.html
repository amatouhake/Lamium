レシピの選び方のモック

L-370。欲しい物「トウヒの板材 7」と「チェスト 1」を開いた内訳で、レシピの選び方を 3 通り並べています。どの案にも「自動」（Lamium が決まりで選ぶ: 作業台 → 石切台 → かまど、その中でゲームの優先度と結果と同じ名前の材料）があり、選んだあとでも自動に戻せます。どれでもよい材料（板材）も同じやり方で選びます。工程のマスと素材の絵は同じ列にそろえ、材料は矢印に向けて右寄せ、結果は決まった列です。押して試せます。

A: 候補をいつも並べるレシピが複数ある工程の下に、候補を小さな札で並べる。札は材料の絵だけ。押すとすぐ替わる。先頭は「自動」。押さなくても候補が見えるが、行が増える。

B: 工程を押すと開く（ボタンなし）工程の行そのものを押すと、その下に候補がマスで開く。一番上が「自動（いまは n 番）」。ふだんは何も増えないが、自動か選んだのかは見えない。

C: 状態をいつも見せ、押すと開くB と同じ開き方に加え、工程の右に「自動」か「選択」をいつも出す。選んだ工程が一目で分かり、自動に戻せることも分かる。

決めたいこと: A / B / C のどれか。どれでもよい材料も同じやり方でよいか。
