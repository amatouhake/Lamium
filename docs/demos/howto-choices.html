作り方の選び方（L-389）と、種類の並び順

「作り方」で行を開いたときの選び方を、今の形と案 C（上に「選び方」の行、下に候補）で比べる。押すと選べる。下の「並び順」は、どれでもよい材料の種類（板材など）を、この欄とツールチップでどの順に並べるか。

開いている行
種類の並び順

今の形アイテムは「自動」「集める」「各レシピ」を縦の行で。グループは「どれでも」と種類をマスで横に並べ、たどるグループにだけ「集める」の行が別にある。

案 C：選び方の行＋候補上の行はアイテムもグループも同じ 3 つ（自動／どれでも、集める、選ぶ）。「選ぶ」の下にレシピの行か種類のマス。選ぶ以外のときは下は薄く、押せばそれを選ぶ。

見るところ

  • 「集める」がいつも同じ場所にあるか（今はアイテムは 2 行目、グループはたどる物だけ別の行、たどらない物は無い）。
  • 案 C で、たどらないグループ（石炭・木炭）は「どれでも」がそのまま集める意味なので「集める」を出さず 2 つにしている。3 つそろえて「集める」を押せないように薄く出す手もある。
  • 案 C の「どれでも」は何をするかを下の小さい字で言う（「原木から作る」「集める」）。今は言っていない。
  • 「自動」と「どれでも」は同じ場所（1 つ目）。アイテムの自動は「いまは〜」、グループのどれでもは「〜から作る」。

種類の並び順

  • 今：ゲームが持っているタグの順をそのまま使っている（板材は「歪んだ → トウヒ → ジャングル → オーク…」）。ツールチップの種類のマス、作り方のマス、ホイールで見ていく順、どれも同じ。規則が無いように見える。
  • 名前順：表示名の五十音（言語で変わる）。探しやすいが、オークとダークオーク、原木と樹皮を剥いだ原木が離れる。
  • アイテム一覧と同じ順：クリエイティブの並び（オーク、トウヒ、シラカバ…、竹、真紅、歪んだ）。Lamium のアイテム一覧もこの順なので見慣れている。原木の 48 種類も木ごとにまとまる。
  • 決めたいこと：案 C にするか（たどらないグループの「集める」の扱いも）、種類をどの順に並べるか。
