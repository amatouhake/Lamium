地図のレイヤー：目印と情報

地図に描く 5 つを「目印」（ウェイポイント・設計図・形状）と「情報」（スライムチャンク・レーダー）に分けた形の確認です。上部バー、情報パネル、目印がオフのときの見え方、設定画面の並び、ワールドマップのレーダーを並べます。地形は仮の絵です。

1. 上部バーの幅

ゲーム内の GUI 単位で描いています。UI 75/100/125% の横幅は worldmap-review.html で測った値（約 673 / 505 / 404 単位）です。右端に赤線が出ているものは 1 行に収まりません（今の実装では切り替えを記号だけにし、それでも入らなければ 2 行目に回します）。ブラウザの文字はゲームより 1 割ほど細いので、ゲームでは必要な幅が 1 割ほど増える見込みです。

2. 情報パネルと、目印がオフのとき

「情報 ▾」を押すと、「地表」と同じようにボタンの下にパネルが開きます。上部バーとパネルの切り替えは「ワールドマップに出すか」だけを変えます（両方 ⇄ ミニマップ、ワールドマップ ⇄ なし。レーダーとスライムはワールドマップ ⇄ ミニマップ）。押したり乗せたりして、3 の設定画面と合わせて確かめてください。ミニマップだけの項目はここではオフに見え、乗せると下のバーにそう出ます。設定の「地図の目印」をオフにすると、目印 3 つは押せなくなります。

3. 設定画面（地図のセクション）

左が今、右が案です。キーの欄は見出しが持つ切り替えのキーです（未割り当ては「—」）。緑の点線は新しい行、黄色は移った行です。「表示する地図」はクリックで切り替わり、2 の上部バーと情報パネルにもそのまま反映されます（逆も同じ）。

4. ワールドマップのレーダー

レーダーの種類の設定どおりにモブとアイテムも出します。引くとプレイヤーの周りに固まるので、ある縮尺より引いたらモブとアイテムは出さず、プレイヤーだけにします。縮尺を変えて、どこから出すのがよいか比べてください。

決まっていること（BACKLOG L-297）

  • 目印（ウェイポイント・設計図・形状）は「地図の目印」見出し（切り替えとキー）の子に、項目ごとの「両方 / ワールドマップ / ミニマップ / なし」。
  • 情報のレーダーとスライムチャンクは独立した見出し（切り替えとキー）で、子に「表示する地図: 両方 / ワールドマップ / ミニマップ」。
  • 「地図のレイヤー」（ミニマップの子）は廃止。オフにしていた人は目印 3 つが「ワールドマップ」になる。
  • 切り替えが効くのは地図だけ。ワールド内の目印・ゴースト・形状、情報 HUD のスライムの行はそれぞれの設定のまま。
  • 上部バーは目印 3 つ＋「情報 ▾」。名前が入らない幅では今と同じく記号だけ。情報パネルはスライムとレーダーの 2 行だけで、レーダーの種類は設定画面。
  • 上部バーとパネルの切り替えは「ワールドマップに出すか」だけを変える。目印がオフのときは押せない見た目で理由を出す。
  • 設定の並びはミニマップ → 地図の目印 → レーダー → スライムチャンク → ウェイポイント → ワールドマップ。「地図の文字」はミニマップの小見出しのまま。
  • ワールドマップのレーダーはミニマップと同じ種類を出し、モブとアイテムは 1 ブロック 1 単位から。

確認したいこと

  1. 選択肢の名前：「両方 / ワールドマップ / ミニマップ / なし」でよいか。行の名前は目印では項目名（ウェイポイント…）、レーダーとスライムでは「表示する地図」。
  2. 既定値：目印 3 つとレーダーは「両方」、スライムチャンクは「ワールドマップ」。推奨 スライムは常に緑が出るとミニマップがうるさいため。
