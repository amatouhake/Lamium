BACKLOG L-46 · 設定を初期値に戻す

設定リセットの 3 案

一般の設定には今、初期値に戻す手段がありません。項目ごと・機能ごと・すべて、の 3 段階をどう見せるかを比べるモックです。下の画面は操作できます。黄色の印が付いているのが初期値から変えた項目です。

案 A

変えた行にだけ ↺ が出る

  • 値の右に ↺。押すとその項目だけ初期値に戻る。下の説明欄に初期値を表示。
  • 機能の見出し行に「↺ 機能」。子の項目がどれか変わっているときだけ出る。
  • 全般に「すべての設定を初期化」。押すと確認画面。
  • 見ればすぐ分かる。マウスで 1 クリック。行が少し混む。
案 B

印だけ出して、操作は右クリックとキー

  • 変えた行の名前の前に小さな印。表は今と同じ見た目のまま。
  • 行を右クリック、または選んで Backspace で「初期値に戻す」。見出し行なら機能ごと。
  • 全般の「すべての設定を初期化」は A と同じ。
  • 表がすっきり、キーボードでも使える。操作に気づきにくい（説明欄で案内）。
案 C

サイドバーに「変更した設定」

  • サイドバーに件数付きの「変更した設定」。開くと変えた項目だけが機能ごとに並ぶ。
  • 各行に ↺、上部に「すべて初期値に戻す」。ほかの画面では印だけ。
  • 何を変えたかを一覧で確かめられる。戻す操作が 1 か所に集まる。行の場所から直接は戻せない。

確認したいこと

  1. どの案にするか。組み合わせ（例：A の ↺ + C の一覧）もありです。
  2. 「すべて初期化」に含めるもの。確認画面で選べる形にしています。キー割り当てと HUD レイアウトは既定で含める・含めない、どちらにしますか。形状はワールドごとのデータなので含めない案です。
  3. 機能ごとのリセットにその機能のキー割り当てを含めるか。モックでは含めません（キーはホットキー画面の Reset で戻せます）。
  4. 元に戻す（Undo）が要るか。モックでは戻した直後に通知だけ出します。
