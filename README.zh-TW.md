## 狀態

Lamium 0.3.0 是早期（0.x）版本。主要的設定、快捷鍵、HUD、高亮顯示、攝影機和疊加顯示功能，
都已在 Minecraft 本機單人遊戲中實際操作過。地圖功能也在外部 BDS 上檢查過；其他功能在伺服器上、
控制器，以及各種資源包和圖形設定上的測試仍不完整。設定中標示為實驗性的功能仍在調整中（請見
[已知問題](#已知問題)）。實際遊戲中的驗證紀錄與尚未涵蓋的部分，記錄在
[驗證狀態](docs/VALIDATION.md)。

支援：Minecraft 基岩版 1.26.51.01、LeviLamina Client 26.51.5 以上（26.51 系列）、Windows x64。
目前沒有支援 Android 的計畫：那需要另外移植成 ARM64 版本，而不是重新包裝現有版本。在 Lamium
尚未檢查過的遊戲版本上，依賴遊戲版本的部分（例如夜視的光照、偽潛行、連接材質、虛影方塊）會維持原版行為；
設定畫面、切換通知，以及進入世界時的通知，會告訴你哪些功能已暫停。

## 安裝

**LeviLauncher（推薦）。** 在裝有 LeviLamina Client 26.51.5 以上、Minecraft 1.26.51.01 的實例中，
從 LeviLauncher 的模組瀏覽器（Bedrinth）找到 Lamium 並安裝。更新和解除安裝也用同樣的方式，
更新會保留你的設定。啟動 Minecraft、進入世界後按 `L` 開啟 Lamium 設定。

**LIP CLI（進階）。** Lamium 的 LIP 套件是 `github.com/amatouhake/Lamium#client`，與 LeviLauncher
安裝的是同一個（在實例資料夾中執行 `lip install github.com/amatouhake/Lamium#client`）。
維護者只測試過 LeviLauncher 的安裝方式。

**手動安裝 ZIP（備用）。**

1. 為 Minecraft 1.26.51.01 安裝 LeviLamina Client 26.51.5 以上版本。
2. 從 [Releases](https://github.com/amatouhake/Lamium/releases) 頁面下載
   `Lamium-<version>-client-windows-x64.zip`。
3. 解壓縮，讓 `Lamium.dll` 和 `manifest.json` 位於 `<實例>/mods/Lamium/`。直接解壓縮覆蓋舊版會保留
   `config/`；不要先刪除資料夾。從 0.2.0 起，ZIP 不再包含 `Lamium.pdb`；符號檔是另一個附件
   （`Lamium-<version>-client-windows-x64.pdb.zip`），只有在需要解讀當機位址時才用得到。
4. 啟動 Minecraft、進入世界後按 `L` 開啟 Lamium 設定。

不要混用兩種方式：手動複製到由 LeviLauncher 管理的 Lamium 資料夾，會讓 LIP 的檔案紀錄過時。

設定儲存在 `mods/Lamium/config/`，日誌寫在 `mods/Lamium/logs/lamium.log`。手動安裝時，刪除整個
`mods/Lamium/` 資料夾也會一併刪除執行時產生的設定和日誌。從 LeviLauncher 解除安裝會移除 Lamium
的檔案，但保留 `config/` 和 `logs/`，之後重新安裝時會沿用設定；如果也要移除它們，請在解除安裝後
刪除 `mods/Lamium/`。受管理更新的檔案歸屬與保留規則記錄在 [Distribution](docs/DISTRIBUTION.md)。

## 功能

在世界中或標題畫面按 `L` 開啟 Lamium 設定。每個功能在那裡都有一個開關，也可以用它的按鍵切換；
變更會立即儲存。*實驗* 表示實驗性功能，仍在調整中。**按鍵** 是預設按鍵（「—」：在你綁定之前沒有按鍵）。
**預設** 是全新安裝後的狀態（「—」：沒有開關的按鍵或畫面）。各功能的詳細說明（英文）：
[Features](docs/FEATURES.md)。

## 已知問題

歡迎在 GitHub issues 回報問題、提問和修正翻譯；回報時哪些資訊有幫助、PR 如何處理，請見
[Contributing](CONTRIBUTING.md)。每個功能在遊戲中檢查過的項目，記錄在 [驗證狀態](docs/VALIDATION.md)。

**攝影機與視野**

- **靈魂出竅：** 地下地形的繪製已在本機世界和 BDS 上檢查；按住/切換操作、選單、失去焦點和跨維度移動也檢查過。
  其他玩家仍會看到你的身體，在伺服器上也能使用（維護者自己使用中）。控制器和更多圖形/資源設定仍未測試。
  如果在頭部位於方塊內時啟動，攝影機飛行時會一直維持在方塊內的畫面；請先離開方塊。只移動攝影機不會讓遊戲
  生成新的地形。飛到已載入區域的邊緣外時，攝影機可能只會顯示天空（L-227）。曾回報過一次切換維度或傳送後出現
  大片地形缺口，但 A/B 測試中沒有再發生；走近就會重新載入（L-243）。
- **隱藏效果：** 還無法隱藏雕刻過的南瓜和望遠鏡的覆蓋畫面。水、熔岩和粉雪的霧氣隱藏，只在原版資源和精美影像下
  檢查過；其他資源包和圖形模式未驗證。在絢麗視覺下，遠處霧氣維持原版（0.1.8 曾因隱藏它而讓世界變成洋紅色並
  閃爍），夜視也沒有效果。
- **連接材質：** 只在本機世界、原版資源和精美影像下檢查過；絢麗視覺、資源包（不同的邊框寬度）和伺服器未驗證。
  只有玻璃、玻璃片、書架和沙岩會相連。相連的玻璃片會在接合處把玻璃拉伸一個像素，而不是維持材質原本的比例
  （若照比例繪製，玻璃片的一半會變暗）。

**HUD 與疊加顯示**

- **玩家列表：** 只有在其他玩家與你在同一個維度時才知道他們的位置；在其他維度時，會以淡色顯示最後看到他們的
  維度，不顯示距離。已在本機、BDS 和區域網路世界中檢查。
- **物品圖示：** 附魔的盾牌在 Lamium 的物品圖示（副手欄位、界伏盒/束口袋預覽、物品欄 HUD）中沒有附魔光澤；
  附魔金蘋果等平面圖示則有。附魔的皮革護甲在那裡，無法染色的部分會變成透明（未附魔的皮革會完整繪製）。

**地圖**

- 小地圖、雷達和世界地圖已在本機和外部 BDS 上，以大範圍已探索區域檢查過。依伺服器分開儲存路徑點、專用伺服器上
  遠處的玩家，以及最新的區段請求/傳送變更，在伺服器上仍未驗證。
- 有些伺服器可能認為隔牆看見生物和玩家不公平。
- 少數生物的頭像還不正確（蠹魚和蝌蚪仍顯示為圓點；駱駝和疣豬獸的臉可能看起來不對），使用自訂頭部模型的外觀
  尚未測試。

**藍圖**

- 只在本機世界檢查過；伺服器、其他維度和非常大的檔案未驗證。
- 在絢麗視覺下，虛影會失去淺藍色調，蜂蜜的虛影會是黑色。
- 緊鄰真實玻璃或烽火台的虛影面，從某些角度看可能會消失，讓共用的平面變成空的（L-245）。
- 實體模型維持靜止姿勢（狼的尾巴、殭屍的手臂）並使用預設外觀，不會畫出綿羊的羊毛，沒有模型的實體會顯示為虛線框。
  實體只依類型在原位附近檢查，並只儲存類型、位置和朝向。
- 在 3D 預覽中，某些鏤空方塊（海草、怪物生成器）後方的部分可能會缺少，草和樹葉會使用你所在的生態域顏色。

**物品欄**

- **村民所有等級的交易：** 鎖定的交易只在本機世界檢查過。
- **物品欄轉移：** 大量移動和「留下一個」的移動，已在儲物箱、熔爐、釀製台和烽火台畫面中，於本機和測試用 BDS
  上檢查。其他類型的畫面、其他伺服器，以及延遲嚴重的伺服器拒絕移動的情況未測試。拿著物品堆時的 Shift + 點擊
  和丟棄手勢，只在本機世界的儲物箱畫面中檢查過。
- **自動補貨：** 已在本機世界和日常的伺服器遊玩中檢查；伺服器的時序、非常快速的使用或不明確的物品欄變化，可能會
  跳過一次補充。不會補充工具（工具保護會在工具損壞前把它換掉）。
- **死亡時配置還原：** 只在本機世界檢查過；開啟立即重生時，物品欄可能被判斷為已保留，因此不會還原任何東西。
  實際使用時，有時會在你沒預期的死亡後還原，或還原成看起來不對的配置（調查中）。有延遲的伺服器未測試。

**操作**

- **偽潛行：** 已在本機世界、測試用 BDS（包括伺服器的位置修正）和伺服器遊玩中檢查。正常遊玩時會讓你停在邊緣；
  在少數情況下，例如嚴重延遲或邊緣距離設得非常小時，仍可能掉下去。其他伺服器的反作弊未測試。
- **方塊限制：** 破壞模式將會重新設計。
- **快速左鍵 / 快速右鍵：** 每刻多次點擊在伺服器上是否都會生效，尚未驗證。

**一般**

- **遊戲語言：** 曾在世界中連續多次切換遊戲語言而讓遊戲當機一次（標題畫面不會）；Lamium 在世界中每 10 秒只允許
  切換一次。原因不明。
- **略過伺服器資源包：** 已在測試用 BDS 上用外觀資源包檢查。資源包會新增方塊、物品、實體或選單的伺服器，這些
  內容會顯示錯誤。在要求使用其資源包的伺服器上，遊戲本身會關閉你的全域資源包，因此看起來是原版外觀，而不是你
  自己的資源包。
- **簡體中文：** 目前是 AI 輔助的翻譯，並沒有經過審核；歡迎修正（請見 [Translating](docs/TRANSLATING.md)）。
  繁體中文介面已由母語者審核。

## 建置

目標：Windows x64、Minecraft 1.26.51.01、LeviLamina Client v26.51.5。請安裝含 Windows SDK 和 C++
工具鏈的 Visual Studio Build Tools、LLVM（clang-cl）、Git 和 xmake。相依套件由 xmake 解析；不需要其他
同層專案或特定機器的設定。

```powershell
xmake f -a x64 -m release -p windows --target_type=client -y
xmake build Lamium
xmake build LamiumTests
xmake run LamiumTests
xmake build LamiumNativeTests
xmake run LamiumNativeTests
./scripts/Check-Package.ps1
```

套件檢查請使用 PowerShell 7。`xmake-requires.lock` 記錄了 Windows x64 使用的套件版本和儲存庫修訂版本。
複製儲存庫時請保留它；`xmake require --upgrade` 造成的變更，請先檢查再提交。

本專案包含一個用戶端 SDK 配方，會下載對應的 LeviLamina 原始碼標頭檔和官方發布的 DLL 並驗證 SHA-256，
再用 Visual Studio 的 `dumpbin` 和 `lib` 產生匯入程式庫。它不會安裝或附帶該執行環境。請見
[SDK build notes](packages/README.md)。

GitHub Actions 會在 Windows 上建置、執行純邏輯和原生測試以及套件檢查，並上傳開發用的建置檔。main 分支的
CI 目前都有在跑，但 Minecraft 中的實際檢查仍需要本機安裝，無法由 CI 證明。

開發時請使用獨立的啟動器實例。測試 Lamium 時，不要啟用其他會改變相同攝影機或物品欄行為的模組。
